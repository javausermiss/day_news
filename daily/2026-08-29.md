The name field in a marketplace entry is an immutable slug. Once a plugin has been published, its name must not change — users have it installed under that slug, and renaming it breaks their install with a plugin-not-found error.
- To change how a plugin is labeled in the UI, set or update displayName instead.
- If a rename is genuinely unavoidable, add an entry to the top-level renames map in.claude-plugin/marketplace.json so existing installs auto-migrate:
"renames": {
  "old-name": "new-name"
}
The Claude Code plugin loader reads this map and transparently rewrites the old slug to the new one on the user's next sync.
When a plugin's source repository ships skills (SKILL.md files) without a .claude-plugin/plugin.json manifest, the marketplace entry can declare the skills directly using strict: false and an explicit skills array.

Install problems? npm 11 crash · slow cold install · no C++ toolchain
On npm 11.x? npx can crash during install with Cannot destructure property 'package' of 'node.target' (an npm/arborist bug, before GitNexus runs). Use pnpm instead — it builds the native deps explicitly:
pnpm --allow-build=@ladybugdb/core --allow-build=gitnexus --allow-build=tree-sitter dlx gitnexus@latest analyze
Or install globally (npm install -g gitnexus@latest) and run gitnexus analyze. See #1939.
Fastest MCP startup: install globally (npm i -g gitnexus) before running gitnexus setup — this writes an absolute-path MCP config that bypasses npx entirely. On a cold cache, an npx-based MCP install can exceed Claude Code's MCP_TIMEOUT default (~30s).
No C++ toolchain? Set GITNEXUS_SKIP_OPTIONAL_GRAMMARS=1 before npm install -g gitnexus to skip the vendored grammar materialize/build for tree-sitter-dart, tree-sitter-proto, tree-sitter-swift, and tree-sitter-kotlin — those four languages won't be parsed, but install completes in seconds without python3/make/g++. Strict =1 only — any other value falls through to the rebuild.
Behind an HTTP proxy / regional firewall? onnxruntime-node's postinstall downloads optional CUDA binaries from api.nuget.org and ignores HTTP_PROXY/HTTPS_PROXY (#2370). The embedding stack is an optional dependency, so a failed download no longer breaks the install — and it self-heals: the first gitnexus analyze --embeddings (or gitnexus embeddings install) fetches the stack through your npm registry config (mirrors/proxies apply, no NuGet) into ~/.gitnexus/embedding-runtime (override with GITNEXUS_EMBEDDING_RUNTIME_DIR). The on-demand prefix needs Node with module.registerHooks (≥ 22.15 on 22.x, ≥ 23.5 on 23.x); on older Node, keep the stack in the install itself with ONNXRUNTIME_NODE_INSTALL=skip npm install -g gitnexus (works on every supported Node).
About tree-sitter-kotlin: like Dart/Proto/Swift, Kotlin is a vendored grammar (under gitnexus/vendor/tree-sitter-kotlin). Upstream ships source only (no prebuilt binaries), so GitNexus cross-builds the platform prebuilds itself (via the build-tree-sitter-prebuilds GitHub Actions workflow) and vendors them — the same uniform pipeline used for Dart, Proto, and Swift. node-gyp-build selects the right .node at require time, so no C/C++ toolchain is needed. If no prebuild matches your platform-arch, only Kotlin (.kt/.kts) parsing is unavailable; the rest of gitnexus is unaffected.
Deploy GitNexus in one click:
The Blueprint creates two services. gitnexus-server runs gitnexus serve as a private service: no public URL, reachable only over Render's private network, with a persistent disk for indexes and cloned repos. gitnexus-web is the public one. It serves the UI and reverse-proxies /api/* to the server, so the browser talks to a single origin.
At the Blueprint's defaults this runs about $35/month: $25 for the server's standard instance, $7 for the web service's starter instance, and $2.50 for the 10 GB disk. See Render's pricing for other plans.
The deploy generates an access token, and the UI asks for it on first use:
- Open the gitnexus-web service in your Render dashboard.
- Copy GITNEXUS_SERVE_AUTH_TOKEN from its Environment tab.

很多老产品这些年也卷到了 70% 的热效率，但新国标更换了测试方法，所以新老国标的 70% 热效其实是有一点不一样的。在新老国标更换之际，库存品还没有消化完，一定要注意产品的能效标识到底是什么。
烟机的新国标还没有更换，但新国标对这个品类而言带来的改变其实更大。
感知度最高的首先是气味降低度。老国标的气味降低度是半小时降低 90%，由于标准宽松基本是个烟机就能做到；新国标则是限时 3 分钟下降 60%，这个标准对于开放式厨房的吸烟效果有极好的保障。
其次是全压效率。原来很多产品都在单纯卷最直观的风量，但全压效率低导致了买了大风量烟机效果也不好。在新国标指导下，直接买一级能效的新品，就能保证烟灶的使用效果不会差。
在这个新老国标的交换之际，我们烟灶怎么选？我想了一下，简单总结就是：灶台看新国标 1 级能效，烟机暂时还是看参数。下面我们就分开讲一下。
油烟机：还是看风量和风压
硬性核心参数：风量和风压
并不是不想提前给大家推荐符合新国标的油烟机产品，而是现在烟机还没有按新国标进行标注。在新国标实施之前，我们还得照风量和风压两个维度来选油烟机。
这里直接给出一个可以抄作业的参数分级表，让你能一眼看出不同烟机的档次。
注意，如果家里是高层住宅楼并且走的是公共烟道，最低最低要选择 1000pa 左右的风压起步。高风压最大的作用是是对高峰期烟道拥堵的压力的。如果你是高层住宅，住的越低，风压就要越选大的。
看到这里，你可能还是不知道烟机怎么选，这就涉及油烟机另一个重要的地方——烟机构型。
主流机型结构区分
烟机的构型目前主要分为以下五种：顶吸、侧吸、顶侧双吸、超薄平嵌、全隐全嵌。除了全隐全嵌目前只用于高端以外，其他 4 种广泛分布在全价位段的产品中。
顶吸
顶吸是最基础的油烟机款式，由于出现的最早，所以顶吸目前广泛存在于低端款当中，高端款偏少。
顶吸的优点在于由于风机上置，所以整个机器做的都比较简洁。特别是随着产品的更新，新款顶吸都普遍做成了超薄款，让整体产品变得更加简洁。
顶吸烟机最大的问题是，由于机器突出一截使用时很容易撞头，相信用过顶吸的朋友都遇到过。哪怕现在烟机往超薄化方向走，依然没有解决这个问题。
侧吸
这里所说的侧吸，指的是最基础的侧吸，不含他演化出来的顶侧双吸、超薄平嵌这两种变体。
这种最传统的侧吸，目前只存在于各种低端产品和入门产品了。如果性能连上文的基础款都达不到，建议直接放弃选购这种款式。
顶侧双吸
这种构型是结合了顶吸和侧低吸的一种烟机。
它最大的优点在于增加了底部低吸风口，使得油烟刚刚升腾就被吸走，保证了极好的吸油烟效果。并且顶吸部分也能做窄，保证整个烟机能和吊柜齐平，提高了整个厨房的美观性。
超薄平嵌
现在越来越多的厨房设计都讲究一体、美观，在装修设计的指引之下，结合顶吸和侧吸的特点，超薄平嵌烟机应运而生。
这种产品为了保证烟机最后和厨房吊柜齐平，所以厚度都控制在 350mm，并且烟机微微下沉呈一定侧吸的状态，保证了一定的吸烟效果。
全隐全嵌
如果烟机要在厨房里面极致简洁应该怎么办？答案是藏到吊柜里面。效果不好应该怎么办？那解决办法就是用的时候降下来，不用的时候升上去，全隐全嵌烟机应运而生。
当然，受限于升降结构的成本以及新品定位，目前这种构型的产品基本只存在于旗舰款产品当中。
附加功能
除了主力抽油烟的功能以外，烟机还有很多小功能，这里也简单盘点一下。
实用、值得选
挥手智控：挥手控制非常好用，做饭的时候手里有油污，按按钮很容易弄脏烟机操控面板，有了这个功能就能很方便地开关油烟机，目前这个功能基本是标配产品了。
烟灶联动：点火烟机自动开启、关火自动延时关机，使用起来也很方便，现在中档起步的产品基本都标配了这个功能。
自动清洗：油烟机用久了，油污变多会影响烟机的吸力，最佳的办法就是拆开清洗。但拆洗一次基本要 200 多块钱，每年一次价格并不便宜。目前根据价格和效果，油烟机自清洁大致分为 4 个档次。
- 甩干：烟机的风轮会在自清洁模式下高速运转，把油污甩出来。效果嘛，只能说比没有好…….
- 加热热熔：甩干效果不好的原因就是油污久了会凝固在风轮上面，最简单的解决办法就是融化老油，然后甩出来。这个原理就是在风轮上加了一圈电热丝，然后效果比甩干好很多，但缺点也不少，比如只能融化有电热丝的地方，像烟机内壁、风轮的死角，基本就没辙了。
- 水洗：水洗就洗很得全面了，基本上烟腔内的缝隙都能覆盖到。水洗也有分为两种，最基础的就是冷水洗，把冷水滋到腔体内部每一个角落，保证每个角落都能清洗到位。但冷水的效果对顽固油污的效果还是不好，所以就有了蒸汽洗这个升级方案。
- 蒸汽洗：蒸汽洗基本上是清洁烟机效果最好的技术了，你们找那种上门清洗服务，师傅用的清洁设备就是蒸汽清洁。目前已经有厂家敢承诺，采用了这个功能的烟机，只要定时清洁，能做到 10 年风力不衰减。
不加价还行的功能
空气净化：烟机的空气净化功能就是换气，通过集成 PM2.5 传感器可以实现自动换气，如果你把家里最远端的窗户打开，其他窗户关掉，它还能实现全屋换气，效果可能比新风还好。
智能家居：智能家居可以算是当做买赠的功能，烟机这个品可千万不要把这个功能放到功能排序的第一序列。目前来说烟灶最核心的还是排烟、炒菜两个功能，不需要智能家居。
鸡肋、没必要加价
大屏娱乐、联网影音、语音控制。
这几个纯属是搞笑的功能，前两个不用说了，第三个看起有用，但实际上炒菜的时候根本听不见。而且很多烟机的语音模块还要单独加钱。
有人说语音可以控制风量大小，其实也完全没必要，现在好一点的烟机，都有自动风量控制功能，可以根据烟的浓度自动调风量。
请千万不要为了完全用不上的功能付钱。
燃气灶：核心参数通俗易懂科普
硬性核心参数
热负荷：家用常规火力区间，避开虚标超高火力机型
热负荷就是火力大小，当前常见的热负荷是 4.2-5.2 kW。这里有一点需要注意，国标规定家用燃气灶单个燃烧器的热负荷不能大于 5.23 kW。
现在有很多杂牌灶为了追求大火力，直接虚标或者把商用灶当做家用灶卖。
燃气管理条例禁止家庭安装商用燃具，存在安全隐患且燃气公司可拒通气、整改处罚，这种灶千万不要买。
热效率：2026 年灶具第一优先级参考标准（国标已经更换）
热效率是指，同样大的火力，能有多少热量转化到炒菜上。
举个例子，同样是 5.2 kW 的灶台，63% 热效率 5.2 kW × 63% = 3.276 kW 有效火力，而 70% 热效率，5.2 kW × 70% = 3.64 kW 有效火力。热效率越高，升温更快、更省燃气，长期使用明显降低燃气费。
2026 年 3 月后出厂灶具，优先认准 ≥70% 热效率一级；64% 仅为二级；低于 59% 不合格。现在这个阶段还有很多库存老款 63% 一级灶，节能性能不如新款 64% 二级灶，选购时候不要被骗了。
盛液盘材质：不锈钢、搪瓷
买灶具，关注好热效率和热负荷，基本就够了。对于灶具来说，有一个有关使用打理的小细节需要注意——炉头下的盛液盘。
相信很多人在炒菜或者烧汤的时候，都遇到过溢锅的时候，事后的清洁也比较麻烦。盛液盘常见有两种材质，一种是不锈钢、另一种是搪瓷。一般来说搪瓷材质的盛液盘更容易打理。
附加功能划分
除了最核心的火力以外，现在的烟灶还有一些功能比较实用，大家可以根据自己的实际需求选购。
定时熄火
定时就不用说了，煲汤炖菜定时自动关火，无需专人看管，非常非常方便。
防干烧保护
部分朋友可能经历过锅放在炉子上烧，忘记关火把锅底烧穿的情况。其实，忘记关火除了损坏锅具以外，还容易引发家里火灾，极其危险。
防干烧则是在灶具中间增加一个接触式传感器，灶具能直接检测到锅温的变化，当锅里水烧干，温度骤变就能实现自动断火，这个功能对于家里用火安全非常实用。
现在基于这个防干烧的传感器，比较旗舰的款式还推出了锅温识别功能，这个功能在煎炸或者煮牛奶的时候非常好用。
家装设计专项：结合当下趋势，打造现代化厨房
本文写到此处，按计划已可收尾。但选购指南讲完了「买什么」，如果不聊「买了之后怎么装」，总会觉得缺了点什么。
目前主流品牌烟灶，即便是基础款，核心性能也足以满足普通家庭日常爆炒、炖煮需求。对于自住装修而言，完全没必要追求顶配、极致性能。在硬件性能普遍过剩的当下，我们更应该跳出单品思维，从全屋装修角度来考量厨房布局。
以下结合 2026 年家装趋势与产品趋势，分享一套厨房设计思路。
空间趋势：从封闭烹饪 → 社交化无边界厨房
开放式厨房越来越流行了。具体落地到厨房装修，总结下来有三大表现：
空间更加通透
开放式、半开放式成为主流，核心原因在于厨房的功能属性发生了根本变化。过去厨房就是一个关起门来闷头炒菜的地方，而现在一家人一起备菜、聊天、轮流掌勺，厨房变成了家里最重要的社交空间之一。
打通墙面、做玻璃隔断、用岛台代替实体门，本质上都是在回应这个趋势——让做饭的人不再被关在「小黑屋」里。
动线更加精细
现在新房装修，只要户型不差，厨房基本都会遵循「洗 → 切 → 炒」的黄金三角布局，把无效走动距离压缩到最小。
更讲究的做法还会做高低台设计——水槽区比灶台区高出 8-10 厘米，适配家里主要做饭人的身高，洗菜不弯腰、炒菜不架胳膊，这才是真正的人体工程学。这些细节装之前不觉得有什么，住进去每天用，差距就出来了。
去机械化视觉
电器端的变化更直观。全嵌入、全隐藏的厨电越来越多：烟机不用时可以升降收回吊柜，洗碗机、消毒柜可以定制正面饰面板，做到和橱柜完全融为一体。厨房越来越不像「厨房」，更像是客厅的自然延伸。
这对烟机的外观设计提出了更高要求——前面第三部分讲的超薄平嵌、全隐全嵌构型，本质上都是为这个趋势服务的。
产品 + 套系趋势：超薄嵌入，全屋厨电一体化
基于前文的空间趋势，我们装修时就能有的放矢。具体可以从以下四个方向入手。
电器选择超薄平嵌 / 隐形设计款
选厨电时，优先跳过那些厚重的传统顶吸和侧吸，直接看超薄款甚至升降隐藏款。一款厚度控制在 350 mm 以内的超薄烟机嵌入吊柜之后，视觉上几乎「消失」，整个吊柜区域显得干净利落。
同理，洗碗机、蒸烤箱也尽量选全嵌款式，正面面板可以和橱柜统一定制。
隐藏式管道排布
花大价钱打了一套漂亮橱柜，什么东西最能毁颜值？答案很简单：外露的燃气管、热水器软管、烟管和插座线缆。这些管线像蜘蛛网一样趴在墙上，再好的橱柜也白瞎。
现在不少新品厨电在设计阶段就考虑了管线收纳——比如热水器可以做柜体包裹安装或者原生自带装饰罩。装修时提前做好管线预埋规划，花不了多少钱，但效果天差地别。
材质色调统一
电器面板材质这几年进步很快，玻璃、拉丝、哑光各种工艺越做越好看，但问题在于它们终究和橱柜的板材不是一家人。一个拉丝不锈钢的洗碗机嵌在一排哑光灰橱柜中间，怎么看怎么跳。
好在解决方案已经有了——现在很多嵌入式电器的正面饰面板可以单独定制，直接用橱柜同款板材覆盖，做到和周围柜门完全一致的颜色、质感和边框。这样不管你家是原木风、极简风还是轻奢风，电器都能完美融入。
厨房电器套系化
这两年装修的朋友一定有一个痛点：买电器做功课的时候一台一台地选，每台单看都不错，油烟机是方太的、洗碗机是美的的、冰箱是海尔的、净水器是安吉尔的。结果装完之后发现，这些家电颜色五花八门、边框粗细不一、风格南辕北辙。
更崩溃的是，每个品牌一个 App，手机桌面还得单独建一个文件夹来放。
正因为这个痛点太痛，所以这两年各大品牌都在推「套系化」。不仅烟灶做套装，冰箱、洗碗机、净水器、蒸烤箱也逐步纳入同一套系。同系列产品统一外观——同色、同质感、同边框、同操作逻辑，整间厨房从视觉到体验保持高度一致，彻底告别混买造成的拼凑感和割裂感。
目前方太、老板、华帝、美的等主流品牌都有自己的套系方案，装修前可以先看看这些套系化产品，然后在这个框架内按需增减单件，比东拼西凑省心太多。
户型适配：不同面积下的厨房设计落地方案
前面讲了趋势和产品方向，但落到实际装修时，户型面积不同，策略完全不同。小厨房最怕束手束脚，大厨房最怕空荡冷清，常规户型则考验取舍。下面按三类户型分别拆解。
小户型（套内厨房≤ 6㎡）
小厨房的核心问题就一个词：不够用。台面不够、储物不够、站两个人就转不开身。所以设计的首要目标，是「榨干每一厘米」。
首先是格局。面积小到这个程度，封闭式厨房基本等于一间闷罐，建议果断做开放式或半开放式。打掉非承重隔墙，用岛台或吧台做区域分界，既释放了空间感，岛台本身还能充当操作台 + 餐桌 + 储物柜三合一，一鱼三吃。
小厨房的开放式厨房对烟机的吸烟能力要求更高——所以小户型选烟机，风压和风量能力必须拉满。
其次是收纳逻辑。地柜尽量全部做成抽屉而非平开门，抽屉的利用率比隔板高至少 40%。吊柜要做到顶，不留那条藏灰的缝隙。墙面也别浪费，现在有那种搪瓷护墙板——这样刀架、挂杆、壁挂垃圾桶都能统统上墙，把台面腾出来，而且磁吸组件还能随时调整位置。十分方便。

[港剧] 日落下的彩虹
- 关键词： 剧情
- 又名：Under The Rainbow
- 片长：45 分钟左右（单集）× 15 集；豆瓣链接
彩虹说要告别，那必定也是要有温度的。
@潘誉晗：2024 年 10 月 30 日，香港政府宣布，将在 2028 年拆除并重建彩虹邨。彩虹邨是香港最早兴建的公共屋邨之一，楼宇外墙那斑斓鲜亮的马卡龙款配色，让它收获了「香港最美屋邨」的美誉。只是很可惜，这栋有着 60 年历史的彩虹邨即将消失，不过好在 ViuTV 推出了这部写实类的单元剧《日落下的彩虹》。
剧集以彩虹邨为故事背景，讲述了七个发生在此的单元小故事。这里的老牌上海理发厅，是一对外人眼中的模范夫妻打理的，借着彩虹邨即将拆建的机会，他们决定直面深埋已久的秘密；单亲妈妈独自抚养三姐弟长大，本该互相扶持的他们，却因这次拆建分房，撕破了亲情的最后体面；积怨多年的父子也决定尝试解开心结……每个人都将面临告别，每个人也因为这场即将到来的离去，开始重新审视自己。
剧集没有那种宏大的叙事，却用这些简单而又普通的故事，缓缓叙述着爱情、亲情、友情的真实模样，动人且暖心。

墨西哥版《布莱切利四人组》。
@潘誉晗：本季时间线为首季结束一个月之后。一个月前，民众还盛赞警方抓获了脱衣杀手，可现在，因警方武力镇压学生游行时所发生的冲突，警民关系迅速跌倒谷底。另一边，一名学生在家中惨遭杀害，其小拇指和食指被切断并带走，因其性取向及在同志酒吧兼职的关系，警方逮捕了他生前的情人。可女警们不这么认为。瓦伦蒂娜参加葬礼时，意外发现死者和友人们合照中曾比划的手势，她敏锐地觉察出这一切和学生运动有关。
阔别两年，冷门口碑剧《女警出更》第二季终于姗姗来迟。故事依然围绕四位女警展开，虽然玛丽亚、瓦伦蒂娜、加比娜和安赫莱斯重新穿上了蓝色的制服，可惜她们没有获得该有的尊重。哪怕她们在之前的脱衣杀手一案中功不可没，但这是 1971 年的墨西哥。她们寻找案件真相，也扛住所遭受的职场压力和偏见。复古的质感与紧凑的节奏完美配合，刻画出了女警们的勇敢和动人友谊。
[英剧] T 教授 第五季
- 关键词：剧情 / 犯罪
- 又名： Professor T Season 5
- 片长：50 分钟左右（单集）× 6 集；豆瓣链接
当冷静的断案天才，开始有情感。
@潘誉晗：贾斯珀（即 T 教授）和海伦娜的恋情稳定发展着，他们决定好好地去度个假，可惜，命运注定要给贾斯珀的生活带来点刺激的东西。就在他们入住的高级水疗中心，两起因食物所引发的命案发生了。所有人都觉得这是意外，可贾斯珀敏锐地发现了疑点，坚信这是谋杀。
翻拍自比利时同名作品的剧集《T 教授》本次迎来了系列第五季。而到了第五年，故事的剧本也越发扎实，在人物情感的处理上，观众真的看到了贾斯珀的成长（虽然他已不算年轻）。作为一名来自剑桥大学的天才犯罪学教授，贾斯珀冷静、客观，因为太过强迫症的关系，他甚至有些自闭。他的断案天赋让他在破案时屡战屡胜，但他的克制也会让他略显不近人情。好在剧集给了他情感变化的空间，他恋爱了，更会表达了；在这一季中，也因为母亲的去世而情绪失控。恰到好处的情感剧情点缀在剧集一集一案的模式中，让故事更加丰富，也更有看点。
[电影] 无界之环
- 关键词：剧情
- 又名：Straight Circle
- 片长：108 分钟；豆瓣链接
你中有我，我中有你。
@利兹与青鸟：在一片荒漠中，两个虚构国家的分界线是一道铁丝网，停战协议签署后，两国同时在这里举行仪式，各派出一名士兵驻守在边境之地。两国争相奏乐、调大音量，在音响的啸叫声中结束了这场严肃又滑稽的仪式。两名士兵不但要每天枯燥地执行升旗、放飞和平鸽、巡逻、修补铁丝网等行动，晚上甚至要睡在同一座简陋的堡垒中，补给也没人按时发放。两个人的性格和理念就如他们头发的长度一样天差地别，一个崇尚规则、遵守秩序，一个自由散漫、粗野善良，但他们却要一起面对孤独、危险与身心创伤。
电影的故事充满寓言式的讽刺，在恐怖和荒诞、现实与想象中来回转换，既探讨相似、分歧与仇恨的由来，也诉说等级与战争对人的异化。电影的视听语言更是极具艺术感，构图十分讲究、色彩对比鲜明，让人在天空的蓝与沙漠的黄中沉醉，又在暴突的血管与猩红的面孔中惊醒。剪辑也很有趣，通过分屏和平行剪辑展现两个国家的不同视角，再合二为一，人物的界线也如画面一样从清晰慢慢模糊。
[电影] 废用身
- 关键词：剧情
- 又名：廃用身
- 片长：125 分钟；豆瓣链接
没用的东西，就该舍弃吗？
@利兹与青鸟：废用身指瘫痪且无恢复希望的肢体，比如因脑梗不能恢复的手臂、因外伤不能恢复的双腿，比起拖着绵软无力的残肢给自己和家人增加负担，在照护资源不足、且遵循患者本人意愿的情况下，切除废用身看起来确实是无比理性的治疗方案。可在伦理与人情上真的如此吗？
疗养院的漆原院长对待病人温和耐心，会为了不打击病人的意志做徒劳无功的工作，也会真心关切病人身上出现的异常情况。但医护因此怨声载道，患者毫无尊严且生活质量每况愈下，他无力改变现实，于是想出了这个疯狂的治疗方案，也确实有人因此受益。可事态却未随着漆原的救赎理想走向光明，而是由人性之恶、舆论审判、极端思想将其扯向深渊。
电影改编自久坂部羊的同名小说，有着如恐怖片般幽暗阴郁的色调，却平和而非猎奇地展现受伤的创口、溃烂的肢体、家人的虐待，有一种平静的惊悚感。片中对不同家庭中失能老人的刻画也惹人深思。染谷将太把亦正亦邪的漆原医生塑造得很出色，在道德与理想的边界痛苦挣扎。

走流程还是直接电？
@SHY：镰仓幕府覆灭后，藏匿于诹访大社的继承人北条时行，在神官赖重的帮助下，结识了值得信赖的伙伴，暗中聚集反抗势力。而在京都，足利尊氏的势力也在稳步扩张，其弟直义于镰仓推行的新政同样大受欢迎。轰轰烈烈的时代浪潮中，以天下为赌注的反乱，将会走向何方？
即使原著质量一路下滑，才华横溢的动画主创，也能用实力掰回风评。超级制片人梅原翔太带领 CloverWorks 的年轻团队，尽情挥洒无处安放的小巧思，活用预知设定，大胆塞入现代元素。不拘泥于表现形式，实拍、定格、拼贴等各种手法多管齐下，呈现令人眼花缭乱的趣味演出，颇有同制作组的《孤独摇滚！》风范。
动画立足稳健的作画水准，古朴亮丽的和风美术，搭配赏心悦目的精美人设，画面观感格外舒畅，不经意的小动作撩拨人心。不拘泥于死板的武士道，活下去才是胜利，以「逃跑」为借口，构思天马行空的新概念作战。既有超群的娱乐性，又不失正剧风采，这场聚焦冷门历史的「鬼捉人」游戏，相信仍会让观众看得津津乐道。

[动画] 时光代理人 第三季
老店重开，没做好心理准备。
@潘誉晗：为找出夏斐失踪的真相，程小时和陆光借助照片和超能力回到了过去。等程小时附身到了夏斐身上，他们才发现这不是简单的失踪案。这群知名模特或网红先是被带到酒会上，要求陪客；之后被带到了缅挝的园区里，并被严格看管。只可惜，因陆光的强烈要求，程小时最后还是回到了现在。不过第二天，夏斐就拎着行李箱出现了。另一边，一位名叫 Jae 的英都警察出现了，为的就是调查缅挝园区被屠事件。
《时光代理人》第三季带着诸多的信息量回来，首集先是把时间线设置在 2007 年，交代了程小时和陆光的童年羁绊，紧接着第二集就承接上季，以夏斐失踪作为切入，引出 Vein 的回归。前期被埋下的大量伏笔也开始逐步被解开答案，乔苓的能力觉醒、程小时父母下落之谜，也在这一季显露端倪。

完美延续了以往系列动画的风格，《飞出个未来》的第十四季依然脑洞大开，也依然在又恶搞又疯癫的剧情中，用科幻喜剧的外表，包装着讽刺现实的内里。利用蚊子血复活牛，结果被复活的牛并不开心，因为它们注定要被宰杀；住在养老院里的机器人们，陷入了诈骗犯为他们精心制定的骗局里；高文明环状星球的主人，竟然是一群老鼠……

[纪录片] 前浪 第二季
要把老人当人看。
@潘誉晗：你有没有设想过自己的老年时光？如果你只有一个人，你会怎么过？如果到了你垂垂老矣的时候，你的身边没有伴侣和孩子，亦或者说没有血缘亲属相伴，只有你一个人，你会怎么处理自己的身后事？
由上海文化发展基金会参与资助的《前浪》第二季，低调地回归了，也很好地回答了这些问题。作为一档走进老年人世界的节目，节目组不夸大，也不回避，直接用镜头记录了老年人的日常生活。于是我们看到了这样一群请求市政府公证员帮助他们选择意定监护的老年人。他们明白自己的人生即将达到终点，他们希望在生命的最后，还能自己做决定；也惊讶地发现，那位潇洒的红娘老九手里，竟然有超过两万多人的老年单身会员……
原来年老只是年龄上的体现，每个人对于情感的需要和追求，不会因为年纪的增长而变小。节目组饱含人文关怀的视角，再一次告诉人们，老人虽老，但依然要被认真对待。

开学季
少数派的读者中有不少学生朋友，而对这个暑假之后即将进入大学的读者来说，接下来摆在眼前的可能是新的城市、新的生活环境和新朋友，以及更多可以自由安排的时间用来学习、探索。
因此和往年一样，少数派也将整理一系列围绕开学季这个话题的内容与资源，不管你是打算为自己挑选一台好设备、好工具，还是投身知识与书本、发展一门新爱好、充实自己的大学生活，这些文章都能为你提供一些参考和帮助。
开学的日子转眼就到了。同样来得迅速的还有毕业的日子。对大部分大三大四的准毕业生来说，毕业论文是面前稳稳横着的一道坎。而如果你是新生，尽早拥有一个良好的阅读文献、整理文献、总结问题的习惯，你的大学学术生活会比其他人轻松得多。
在少数派，我们有不少作者曾分享过自己的知识累积、文献管理、论文写作等各个阶段的经验与方法，他们有的结束毕业论文，有的是在读硕博，还有一些是从事学术研究工作的大学教师。在这篇文章中，我们整理了一部分来自这些作者的优质内容，希望能给你的论文写作和学术生活带去一些帮助。
在信息之海中寻找正确的鱼
想要在自己感兴趣的领域深挖，大量的阅读积累必不可少。在实际操作中，面对海量的论文、消息与书籍，要找到真正有用的那几篇，单靠「毅力」和「决心」硬读不可取，更不现实。这时，正确的「信息检索」技巧就能让你更精准地定位需要的内容，达成事半功倍的效果。
检索库，在精不在多
不少同学在准备阅读之初，不知道从何下手，于是去胡乱搜索各式各样的集合帖子，把推荐的十几二十个资源库一股脑堆在面前。等到真要检索时，又被自己攒下的这么多条路震慑，哪条路都走不好。空谷 在《如何构建「思维大脑」：我的信息搜集与整理方法》一文中就指出了这一现象，并根据自己的经验，给常用的书籍、论文、视频以及其他碎片信息四大分类进行了精简的推荐。除此之外，作者还整理了自己的信息整理方法与工作流，供需要的读者参考。如果你正发愁自己的信息检索从何下手，不妨看看这篇文章。
筛选文章，自有技巧
选择了正确的数据库，输入了正确的关键词，蹦出来的论文可能几十，可能上百，若是热门领域，几千篇的数量绝对不是一个学生能一口吃下的。事实上，在检索页面就已经提供了大量的信息，论文详情页和作者详情就足够你筛选一篇合适的文章。鸿苓 的《我的毕业论文选题和文献审读方法，你可能也会用得上》总结了阅读文献过程中的点点滴滴。从文献检索，到简要筛选，再到后续的阅读整理以及论文笔记，每一个环节文章中都有涉及，这些经验或许能帮你把「入门」这件事变得简单一点点。
完善的文献整理工作流是减负利器
在实际的论文写作过程中，我们缺的常常不是论文数量，而是快速找到自己需要的论文。如果没有良好的文献整理习惯，写作时，有一大笔时间都会浪费在寻找正确的可用文献上。「我读过这么一篇文章，但我找不到了」是一种真实的折磨。越早建立一套完整的文献归纳与整理工作流，你就能在后续的研究与写作中越高效。
寻找最贴合场景的工作流
在阅读文献时，你可能遇到各种各样的问题：文献来源有的是纸质书有的是电子版、笔记过于分散、读过的东西时间太久忘记重点、找不到两篇文献之前的联系等等。而每一个人的工作、学习环境都是有所差别的，单纯地照搬可能并不会有好结果。chyixian 是在日本留学的在读文科博士，由于日本的电子化进程缓慢等现实因素，她的文献来源多且杂乱，于是她寻找了一套最适合自己的文献笔记工作流。更重要的是，《文科博士生眼里的资料管理、阅读和笔记系统》这篇文章在记录工具的同时，也记录了她思考和构想的过程，读者可以从这些记录中学到考虑问题的思路，而不只是一个孤零零的结果。
尝试高效的笔记方法
「读到就写，写过就忘」是不少人在进行笔记工作时遇到的大问题。面对混杂铺陈的笔记和感想，无法分散的块组成紧密的网，就没有办法把信息一步步组建成知识，这些读过的东西会因为缺乏关联性逐渐被遗忘。老师们常常说的「在脑中建立知识网络」就是这样的道理，当信息有机相连，才能组成有效的结构。问题在于，在知识网络的构建之初，记忆很难直接支撑起这个庞大网络的结构。这时可能就需要一些有效的辅助手段来帮我们做好这件事。
「卡片笔记法」是德国社会学家尼古拉斯·卢曼采用的一套笔记方法，依靠筛选、索引、标记等一系列操作实现知识点或笔记的连结与检索。和燕燕 在文章中对这套笔记方法以及它的应用做了详细的介绍。如果你不知道怎么整理自己的知识体系，或是不清楚如何摆脱「看完就忘」的难题，这篇文章都能对你有所帮助。不止是文中提到的 Roam Research，你也可以用其他的工具实践卡片笔记法，stevesun 也提供了自己在 Notion 践行卡片笔记的实例，如果你想采用其他工具，可以对照两文进行参考。
另外讨论度较高的就是 P.A.R.A. 系统。这是一个围绕项目与领域的整理方案，把输入的内容按项目（Project）、领域（Area）、资源（Resource）、归档（Archive）一步步整理好，为自己的笔记系统构建一套稳定的、成体系的架构，便于未来的查找与输出。JuniperPhoton 就在 Notion 的笔记中使用了这套体系。如果你不知道每天新获取的零碎知识如何归类整理，可以试试参考一下他的方法。
Yorkson 在文章中分享了他将 P.A.R.A. 系统运用进文献管理体系的方法，你也可以根据自己的研究领域依样学样尝试一下。除此之外，还有其他作者分享的更关注当下任务的 INL 结构可以参考，但这种格式通常更适用于生活笔记，本身框架就足够清晰的学习笔记不一定适用，大家可以在阅读后自行判断。
适合自己的才是最好的
合适的笔记软件会帮你省去不少麻烦，但现在笔记软件的发展已经趋于稳定，各家主流应用早期版本中的核心特色，现在在其他产品里差不多也能找到替代。无论 Notion、Obsidian，还是 Logseq、Heptabase，工具的挑选可以有，但最终还是要落在实实在在的做笔记上。有了思路和方法，工具才能物尽其用。
举个例子，虽然文献管理有非常多优秀的专门应用，但使用已有的笔记应用，照样可以搭出适合自己工作流的文献笔记数据库。木一Benature 的这篇文章就详细描述了自己的 Obsidian 使用方法，他把全部的笔记系统归一，形成了一套围绕 Obsidian 的方案。如果你不知道如何开始，可以参考他的构建方法与思路。
说到底，文献阅读和资料整理这些流程，都是要依据自己的使用习惯、惯用工具等等一系列因素决定的。这就是为什么要「化用」而不是「照搬」。少数派有不少关于文献整理和笔记的文章，而选择这些也是因为它们不仅分享了作者在这些方面的经验与实践，更重要的是它们带着思考的过程，让你知其然更知其所以然。和燕燕的这篇《我们需要什么样的双向链接，它适合你吗？》就对当下大热的「卡片笔记 + Roam Research + 双向链接」模式进行了反思，其实任何方法论都是这样，在使用前、使用中，都可以进行反思与评估，逐渐发觉最适合自己的文献归纳方式，顺利地开始你的研究工作。
也有不少应用集成了 AI 功能来辅助文献管理。比如 macOS 老牌文件管理应用 DEVONthink，在 4.0 大版本中就全面集成了生成式 AI 模型——支持 ChatGPT、Claude、Gemini 等主流大语言模型 API，也可通过 Ollama 或 LM Studio 等接入本地部署的模型。此外，新版本还可以借助 AI 用自然语言搜索文档、自动生成知识图谱、AI 总结文档内容等等。如果你对 AI 影响知识管理的能力还不太了解，其实可以从这篇工具介绍中获得一些启发。
Obsidian 这样更现代的工具自然没有落后。借助强大的插件体系，Obsidan 配合 Claudian 与 Obsidian CLI 也能让知识管理变得自动又轻松。你也可以参考西郊次生林使用 Obsidian 笔记系统帮自己复习高数的实例，看看 Obsidian 的插件体系能如何融入学习过程。
另一种思路是打破传统框架，让自己的笔记直接长成一张图谱。《深入〈无边记〉：一种革命性的知识管理体系》介绍了一套基于 Apple 无边记的知识管理思路。传统的笔记工具都涉及复杂的素材分类和整理环节。而无边记提供了一张无边的画布、一个无界线的收纳盒，可以快速收集碎片化的信息，再统一处理，无需在收集阶段纠结于归类。这种像白板一样直观的整理方式，或许能让面对传统工具无所适从的你快速开始，另外，这样的知识整理方式，或许能在你复习考试时帮上大忙。
让 AI 融入知识管理系统
AI 的浪潮以前所未有的速度重塑着我们的学习、研究和知识管理方式。激进地说，AI 必然与学习和研究产生关联，用是肯定要用的，但单纯让 AI 变身搜索引擎、答题软件，只会让强大的新工具变成进步的绊脚石。如何让 AI 真正有助于自己，是个需要学习、思考，并在实践中反复检验的问题。找到正确的路子，它可以让散落各处的知识以前所未有的速度化为己用。
王树义在《我的 AI 工具日常使用与工作流是怎样的？》一文中分享了自己日常使用的 AI 工具及其分工。他的核心思路是「重器轻用」，不让一个工具做所有事，而是让每个工具在自己最擅长的领域发挥作用。文章对常见 AI 工具的介绍算是比较全面的，思路也可以参考。但需要注意，因为 AI 工具的迭代速度很快，文章中的某些结论可能不再适用，而且使用复数 AI 工具也有成本问题，推荐参考思路即可。
潦草学者的《AI 时代，我的知识管理系统（2025 版）》是作者对自己打磨了超过 5 年的知识管理系统的全面升级与开源。作者将知识管理系统定义为 CARD 四步法：Capture（捕捉信息）、Absorb（渐进式阅读）、Repository（存储到知识库）、Deploy（部署并使用）。每一步都详细介绍了原理、方法和工具，以及 AI 在其中发挥的作用。如果你想从头建立一个有 AI 参与的知识管理体系，这篇文章的每一部分都有很高的参考价值。
Haoo_7 在《年度征文｜效率杂谈：告别纸笔拓荒，怎么用 AI 来辅助学习？》一文中分享的方法则更聚焦于学习生活。文章的核心工具组合是 NotebookLM（AI 知识库）+ Obsidian（Markdown 笔记软件）+ Xmind（思维导图工具），这三者可以串联成完整的学习工作流。方法较上面两篇更为简单，也更适合学生朋友参考。
有做论文的方法才能做出好论文
对于学生来说，以上说的那些检索、阅读、整理的方法，最终还是要落实在自己的创作上。可能是一次小组作业，可能是一篇小课题，可能是毕业论文。这些写作自然也有它们的规律和技巧，掌握正确的方法和思路，你的论文产出还能再顺畅一点。
好的文章从确定选题开始
一篇好的论文，哪怕是一个小的课堂作业（或者少数派的一篇稿子），都要从一个好的选题开始。不少人直到论文答辩近在眼前还想不明白自己的选题，还要靠导师或是同学帮忙，而这样做出的文章，十有八九结果不会好，甚至可能过不了。不妨试试早一些开始，学会寻找现象、发现问题、确定选题，有了科研的思维，自然就可以在这条路上快人一步。Sharon大橘子 的《确定论文选题有多简单？我用少数派给你做个示范》以你正在看的少数派为例，展示了怎么样从一个小小的问题，逐渐演化出一个规范的论文选题。如果你是人文社科类专业的同学，这篇文章可能会对你有所启发。
从学生角度阐述了如何选题之后，我们来看看最终交给导师的选题报告应当如何呈现。玉树芝兰 的这篇文章，以大学教师的身份，从导师的角度探讨了一份论文的选题报告可能出什么问题、可能哪里有弯路。这篇文章就脱胎于他与学生关于选题的对谈。
好的工作方法奠定研究基础
选题有了，接下来就是开始进入研究过程。想要进行一个完善、严谨的研究，正确、适宜的研究方法必不可少。在诸多研究方法中，调查问卷可能是被使用最频繁的，不管是毕业论文还是小组作业，调查问卷总是「看起来」最为方便、最好分析的一个。但在实际操作中，作为方法的调查问卷其实也有很多坑，一不留神就会做出有偏差的问卷，引导出错误的结论。这篇文章按照规范流程为你一点点剖析了问卷设计的注意事项，哪怕参加了工作，这些知识你说不定也用得上。
如果你对科研相关的内容很感兴趣，想进一步学习，不妨看看 @玉树芝兰 王树义老师在少数派开设的付费订阅课程《科研新手全面入坑指南》。专题从选题、文献研究、论文阅读、写作、答辩及其它等六个方面对科研新手可能遇到的问题进行了详细的讲解。你可以前往课程详情页面查看完整的课程大纲。
还有一个绕不开的问题：AI 可以运用于科研吗？
在《Vibe Research：社会科学的第一次 AI 危机？》中，TomBen 介绍了 AI 用于学术研究与论文写作的快速进化，并探讨了「Vibe Research」的伦理与实用性问题。值得一提的是，这篇文章本身也是在 AI 辅助下写就的。文章的讨论内容与文章写作方法本身都很值得进入学业的读者参考。
王树义老师的《AI 算不算一种研究方法？》则从教师的角度出发，讨论了 AI 应该以何种程度进入研究。文章从科学精神中的「求真」与「复现」出发，分析了大语言模型「概率而非逻辑」的本质所带来的先天局限。这种对科研伦理的讨论可能对你的学习研究本身帮助不大，但让自己心中有杆秤，才能保证你学到的、要投入实践的「知识」，不是骗骗自己而已。
好的格式为你的辛苦收尾
经历了一系列折磨，你的论文和报告终于完成了，但距离最终的解脱还有最后一步：格式。与其说论文排版非常神秘，不如说 Word 太神秘——它不方便、不快捷，还总有乱七八糟的小问题，但超高的占有率让它成了无法避开的选择。即使许多学校已经将 PDF 格式当作了首选，你可能还是需要一份 Word 版的初稿来与导师交流反复修改。这份《论文格式调整指南》是作者在完成硕士论文后写出的总结，涵盖了基本上你需要学会的所有 Word 格式操作。如果很幸运，你的专业、学校和导师都允许你采用其他格式和工具，这里还有针对 LaTeX 和 Markdown 的写作工具与流程分享介绍供你选用。
希望你在新的学年里学得扎实、学得快乐，也希望这些文章能在你的学术研究道路上提供小小的助力。
除了以上方法类的内容，如果你已经决定潜心学术，想用更专业的方式管理未来可能大量累积的文献内容，也可以查看我们另外准备的《开学季 | 挑个趁手的工具，尽早学会文献管理》一文。在开始之前了解一下各个主流的文献管理工具，选用更专业的文献管理软件，养成更利于学术发展的习惯，免去后续迁移的麻烦。

- [桌面升级，灯也要跟着进化：明基 iScreenBar 与 ScreenBar Max 体验](https://sspai.com/post/113909) <sub>08-28 09:56</sub>

2017 年，明基推出第一代 ScreenBar，把原本占据桌面的灯座挪到屏幕上方，再用非对称光路照亮桌面、避开屏幕，由此创造了世界上第一盏屏幕挂灯。
此后近十年的产品迭代，大致沿着物理结构和智能体验两个方向展开。灯头变得更轻，安装结构可以兼容更多显示器，非对称光路不断调整照射范围，同时减少屏幕反光；另一边则加入了无线控制器、自动调光、色温调整与人体感应。到了近两年，从 ScreenBar Pro 开始，挂灯已经可以安静地待在屏幕上，自动启闭并调节亮度和色温，使用时几乎感觉不到它的存在。
我们此前体验 ScreenBar Pro 时，最深刻的印象是「似若无物」。它可以恰到好处地照亮桌面，不占空间，也几乎不需要用户主动调整。一个产品能够做到离不开但想不起，意味着它已经非常成熟，我确实很难再想象它还能发生什么明显变化。
但桌面没有停在原地。有人换成了把主机、摄像头、麦克风和扬声器都收进一块屏幕的 iMac；有人把第二块显示器搬上桌面，甚至横竖屏错落使用；AI 时代里，多线程变得越来越频繁，带鱼屏也越来越长。除此之外桌面也未必只放着键盘，纸张、数位板和各种需要动手处理的物件，都在争夺桌面的照明。于是我们看到过去围绕一块标准显示器形成的灯光方案，开始出现瓶颈。
于是在 ScreenBar 十周年新品发布会上，明基带来了全新产品 iScreenBar 和 ScreenBar Max，分别从两个方向回应了数字桌面的变化。
iScreenBar 做得更轻巧，也更靠近 iMac。它顺着 iMac 原有的外观和结构寻找自己的位置，再把灯光控制接入 macOS。安装完成后，iScreenBar 看起来像是 iMac 原本就有的一部分；ScreenBar Max 则离开了单块显示器，独立支臂让灯头可以越过双屏之间的缝隙，调整高度、距离和照射位置；更宽的灯头也把光线带到屏幕之外，照顾整张工作台上的键盘、纸张和其它物件。
前者尽量顺着一台高度整合的电脑去设计，后者则接受大型工作站桌面不断扩张的现实。一个努力降低灯在桌面上的存在感，一个主动承担更多照明任务。两款产品由相同的技术积累创造，形态却满足着不同的场景和需求。
因此，iScreenBar 和 ScreenBar Max 更像是 ScreenBar 产品线向外分出的两套新方案。明基没有重新发明灯，也没有推翻过去十年的设计。它重新观察了灯周围的屏幕、设备和使用方式，再把已经成熟的光学、结构与智能体验放进两张不同的桌面。
藏在 iMac 设计里的 iScreenBar
iMac 很容易被一件不合适的配件破坏掉完整感。
现款 iMac 将人物居中摄像头、三麦克风阵列和六扬声器系统装进同一副机身，颜色、材质与线条也保持着很强的统一性。尽管普通显示器挂灯也能装在 iMac 上，但安装之后厚重的夹具可能挡住摄像头和背后的麦克风开口，线材也会沿着整洁的机身背面突兀垂落。这些在颜色、材质、结构或比例上的偏离，都使得 iMac 原本完整的外观多出了一个醒目的附件，甚至还会干扰其正常工作。
iScreenBar 采用磁吸方式安装，固定结构因此可以做得更轻。灯体的颜色与材质也顺着 iMac 调整，同时避开机身上的摄像头、麦克风和扬声器。线材沿机身背面收拢以后，正面留下的部分只有灯头本身。灯体做得更轻巧以后，照明仍要覆盖 iMac 前方常用的桌面。
iScreenBar 使用第三代 ASYM-Light 非对称光学，将光线集中投向键盘与桌面，让屏幕和眼睛避开直射光。于是尽管灯可以贴近 iMac 安装，但桌面上的照明范围没有因此而打折。
但外观只完成了一部分工作。iMac 的优势一直来自软硬件配合，于是除了成熟的根据环境光照自动调光功能，iScreenBar 还把灯光控制接入了 macOS。其配套应用可以通过 Power Sync 让灯跟随 iMac 开关机。用户坐到电脑前开始和结束工作，灯便会随着电脑启闭。如果设置了人体感应，临时离开桌面时同样不用惦记开关。
应用还能为不同软件保存灯光设置。例如写稿时可以使用偏中性的亮度和色温，处理图片时调用另一套照明，打开视频会议软件后则可以切换到视频通话补光模式，基于环境光照提升视频效果。这件事看上去或许没有硬件参数那么直接，却很符合 iMac 用户的操作习惯。iMac 的许多体验原本就由软硬件共同完成——电脑知道用户正在做什么，然后调整设备状态——只是现在灯光也加入了这套工作流。
iScreenBar 的适用范围十分明确。它围绕 iMac 的机身结构、外观与 macOS 设计，如果换成其它电脑和显示器，许多细节都会失去作用。但对于一台很难随意增加配件的 iMac 来说，iScreenBar 愿意服从电脑原有的设计，恰好构成了它存在的理由。
ScreenBar Max 想要照顾一整张工作台
ScreenBar Max 在假定用户的桌面已经没有一个明确的中心。在单屏桌面上，人、显示器和挂灯大多位于同一条中轴线上。两块屏幕并排以后，人的座位可能对着两块屏幕之间，也可能长期偏向其中一块。显示区域的中心、桌面的中心和用户所在的位置开始互相错开。
传统挂灯固定在其中一块屏幕上，光线容易偏向一侧；放在两块屏幕的接缝附近，又会遇到边框、角度与安装稳定性的问题。如果其中一块显示器竖放，或者换成长比例的带鱼屏，屏幕上方也很难找到一个同时适合安装与照明的位置。
ScreenBar Max 因此离开了显示器顶部。它通过桌夹或者可选底座固定在桌面上，再用独立支臂将足足 85cm 的超长灯头伸到屏幕前方。灯头不需要依附某一块显示器，显示器升降、旋转或者重新排列时，灯的位置也可以单独调整。
独立支臂提供了高度和前后位置的调整空间，基于在用的显示器尺寸，最高支持 55 - 71cm 范围的高度调节，同时还有 17.5 - 28cm 的滑轨前后调节，如果希望光集中在键盘附近，可以将灯头向后移动；桌面上摊开纸张、手账或者正在处理的设备时，也可以把灯头向前伸。
为了让光线能有效覆盖双屏桌面，ScreenBar Max 推出了全新的 ASYM-TriZone 全景非对称光型。得益于 ScreenBar Max 更宽的灯头，照明被延伸到两块屏幕前方，光线主要投向桌面，同时利用遮光设计减少显示器反光和直射眼睛的光线。两块屏幕之间原本容易变暗的位置，也被纳入了照明范围。
更宽的光型还要处理桌面操作产生的阴影，ScreenBar Max 通过交错排列灯珠减少方向不同的多重阴影；灯头背面的环境光则照向墙面，缓和亮屏与暗背景之间的反差。所以它虽然看起来好似一盏传统台灯，但使用体验则截然不同。
除此之外，ScreenBar Max 还将亮度、色温、自动调光和人体感应等控制集中在带显示屏的控制器上。用户可以直接看到当前状态，再根据桌面变化重新设置。对于一盏服务于现代数字桌面的灯具来说，明确且自动调整的照明状态比按键方便得多。
ScreenBar Max 面对的是双屏、竖屏和带鱼屏组成的工作站，以及那些同时承担电脑操作、阅读和手工处理的桌面。它离开屏幕之后获得了更大的调整范围，也接受了更明确的存在感。
让光适应已经改变的桌面
iScreenBar 和 ScreenBar Max 看起来差异很大，但使用的仍然是明基过去十年逐渐积累下来的非对称照明、自动调光与人体感应经验。成熟技术成了两款产品共同的起点，明基因此可以把更多精力放在灯与其它设备的关系上。
iScreenBar 需要理解 iMac，它顺着一体机原有的外观与结构安装，再通过配套软件参与电脑的使用过程；ScreenBar Max 则需要理解日益复杂的桌面陈设与用户需求，它放弃依附单块显示器，通过独立支臂回应不断增加的屏幕与桌面操作。
而这两款新品与旧款之间则没有简单的替代关系。如果你使用的是一块标准显示器，仍然适合传统 ScreenBar Pro 或 ScreenBar Halo，iMac 用户可以选择 iScreenBar，双屏和大型工作站则更容易发挥 ScreenBar Max 的能力。桌面不同，照明需要处理的问题也会随之变化。
这也解释了明基为什么一直在做看上去颇为专用的灯，除了显示器挂灯，还有面向笔记本电脑、阅读和钢琴等场景的产品。笔记本电脑会移动，阅读和练琴时的坐姿和琴谱琴键照明需求也不同。显示器挂灯只是这些具体方案中的一种。
我们过去在分享效率工具时，也经常会遇到类似的情况。参数表只能说明一件产品可以做什么，只有具体的场景才会解释产品为什么长成现在的样子。明基用不同的产品点亮在做不同事的我们，才能看出一个设计究竟是解决了问题，还是只增加了功能。
我以前很难想象显示器挂灯还能发生什么变化，是因为我一直只关注在灯本身。但 iScreenBar 和 ScreenBar Max 跳出了产品，回到真实场景里，在实际体验中改变了灯与屏幕、桌面和人的关系。明基用过去十年回答了一盏显示器挂灯怎样才能做好，现在的两款新品开始处理使用场景的变化：电脑性能越来越强，工作站越来越大，人在桌面上做的事情也越来越多。光源也该有不同的形态和位置。
