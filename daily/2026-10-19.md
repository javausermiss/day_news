Plugins can be installed directly from this marketplace via Claude Code's plugin system.
To install, run /plugin install {plugin-name}@claude-plugins-official
or browse for the plugin in /plugin > Discover
Internal plugins are developed by Anthropic team members. See /plugins/example-plugin for a reference implementation.
Third-party partners can submit plugins for inclusion in the marketplace. External plugins must meet quality and security standards for approval. To submit a new plugin, use the plugin directory submission form.
Each plugin follows a standard structure:
plugin-name/
├── .claude-plugin/
│   └── plugin.json      # Plugin metadata (required)
├── .mcp.json            # MCP server configuration (optional)
├── commands/            # Slash commands (optional)
├── agents/              # Agent definitions (optional)
├── skills/              # Skill definitions (optional)
└── README.md            # Documentation
The name field in a marketplace entry is an immutable slug. Once a plugin has been published, its name must not change — users have it installed under that slug, and renaming it breaks their install with a plugin-not-found error.
- To change how a plugin is labeled in the UI, set or update displayName instead.
- If a rename is genuinely unavoidable, add an entry to the top-level renames map in .claude-plugin/marketplace.json so existing installs auto-migrate:
"renames": {
  "old-name": "new-name"
}
The Claude Code plugin loader reads this map and transparently rewrites the old slug to the new one on the user's next sync.
When a plugin's source repository ships skills (SKILL.md files) without a .claude-plugin/plugin.json manifest, the marketplace entry can declare the skills directly using strict: false and an explicit skills array.
{
  "name": "example-bundle",
  "description": "Brief description of the bundled skills.",
  "author": { "name": "Author Name" },
  "category": "development",
  "source": {
    "source": "git-subdir",
    "url": "https://github.com/example-org/sdk.git",
    "path": "packages/agent-skills",
    "ref": "main",
    "sha": "<commit sha>"
  },
  "strict": false,
  "skills": [
    "./skill-a",
    "./skill-b",
    "./skill-c"
  ],
  "homepage": "https://github.com/example-org/sdk"
}
Each path in skills is relative to source.path and points at a directory containing a SKILL.md. Paths can reach deeper than a single level — for example, ["./libA/skill-1", "./libB/skill-2"] exposes a curated subset across multiple library subdirectories. Each skill is registered as <plugin-name>:<skill-name> in Claude Code.
For the underlying schema, see Strict mode in the marketplace documentation.
Please see each linked plugin for the relevant LICENSE file.
For more information on developing Claude Code plugins, see the official documentation.

Java 17 introduced sealed classes, which allow you to explicitly list the allowed sub-types of an interface or base class. For example, here’s a toy example using a sealed interface and records (inner classes are implicitly added to the permitted sub-types if an explicit list is not given):
public sealed interface SealedType {
    record TypeA() implements SealedType {}
    record TypeB() implements SealedType {}
    static SealedType of(String type) {
        return switch (type) {
            case “A” -> new TypeA();
            case “B” -> new TypeB();
            default -> throw new IllegalArgumentException();
        };
    }
}
If you are familiar with functional programming languages with algebraic datatypes, you can view this as similar to a datatype declaration in Haskell or ML:
data SealedType = TypeA | TypeB
We can then use this in a simple Main class:
void main(String[] args) {
    var val = SealedType.of(args[0]);
    System.out.println(switch (val) {
        case SealedType.TypeA() -> “A”;
        case SealedType.TypeB() -> “B”;
    });
}
OK, not so exciting. But one thing to note here is that we didn’t have to add a default clause to the switch expression in our main method. This is because sealed classes (and enums) enable exhaustiveness checking: the compiler knows exactly what the possible cases are, and so can check if you have covered them all. If you have, then you don’t need a default clause. If you forget one (and don’t have a default clause), then you get a compile-time error.
This is great when you want to ensure that all uses of some type do cover all of the cases, but it does introduce a new type of breaking change: adding a new sub-type to a sealed class/interface may break consumers of that code. For example, adding a new TypeC case to our example will cause the main method to fail to compile due to the missing case. So if you export a sealed type in your API then adding a new subtype is a breaking change that would require a major version bump (if you’re following SemVer).
Compile-time or runtime error?
Although Java will produce a compile-time error for a non-exhaustive switch when you compile the consumer (main in this case), it cannot do so if the consumer is not recompiled when the sealed type changes. For example, suppose that we extend our SealedType with another case:
public sealed interface SealedType {
    record TypeA() implements SealedType {}
    record TypeB() implements SealedType {}
    record TypeC() implements SealedType {}
    static SealedType of(String type) {
        return switch (type) {
            case “A” -> new TypeA();
            case “B” -> new TypeB();
            case “C” -> new TypeC();
            default -> throw new IllegalArgumentException();
        };
    }
}
If we just recompiled SealedType.java and don’t recompile Main, then we end up with a runtime exception if we trigger the new case:

反直觉的 HRV
说起心跳，你脑海中浮现的是什么画面？可能是那个一闪一闪的红色心形图标，匀速地、有节奏地跳动着；也可能是心电图上规整的波形。如果静息心率是 60 次/分钟，那心脏就应该像一个精准的节拍器，每隔 1 秒跳动一次——这似乎是最符合直觉的「健康心跳」。
事实上，在很长一段时间里，医学界也是这么认为的。20 世纪中期以前，不少医生认为稳定、规律的心跳才是健康的标志。如果心跳间隔出现波动，那可能是某种病态的表现。然而，随着医学的不断发展，尤其是 20 世纪 60-70 年代计算机技术的引入，学者们惊讶地发现：健康人的心跳其实是不规律的。
只有濒死或严重受损的心脏，才会像节拍器一样精准地跳动。
1965 年，耶鲁大学的 Hon 和 Lee 在监测胎儿心跳时，意外发现了一个反直觉的现象：那些即将出现窘迫甚至死亡的胎儿，他们的心跳反而变得异常「规律」，胎儿心跳间隔之间的微小波动，会显著减少甚至完全消失。1980 年代，一项更为严谨、更为著名的大样本研究发现：808 名心肌梗死的患者中，心跳变异程度低的人，死亡率远高于心跳变异较高的患者。
由此，人们开始意识到：原来，心跳的「不规律」不是问题，反而是生命活力的体现。一颗节奏完全固定的心脏，就像一台失去了灵性的机器，意味着心脏失去了对外界刺激的响应能力。心跳节律的变化，并非巧合，而是存在一种可以量化、可以预测的规律。在这些看似「混乱」的波动中，其实隐藏着身体状态的密码。
人们开始使用一个指标来量化这种规律。这，就是心率变异性，HRV。
HRV 是什么？
心率变异性（Heart Rate Variability, HRV）是指逐次心跳周期之间时间间隔的微小波动。具体来说，它测量的不是每分钟跳多少次（心率），而是连续两次心跳之间的时间差（RR 间期，RR interval）的变化情况。如果你使用心电图仔细进行测量，实际的心跳间隔可能是这样的：
- 第 1 次跳动到第 2 次：828 毫秒
- 第 2 次跳动到第 3 次：845 毫秒
- 第 3 次跳动到第 4 次：754 毫秒
- 第 4 次跳动到第 5 次：742 毫秒
- ……
如果这些时间间隔变化很大，就是高 HRV；如果每次间隔几乎一样，就是低 HRV。它主要反映了人体自主神经系统（交感神经和副交感神经）对心脏的调节能力。
交感神经系统：
- 扮演着「油门」的角色。当机体面临压力、恐惧或需要「战或逃」 反应时，交感神经系统会激活；
- 其作用是加速心跳、增加心肌收缩力，调动身体能量以应对紧急情况；
- 交感神经激活，会使 HRV 降低。
副交感神经系统：
- 主要通过迷走神经发挥作用，扮演着「刹车」的角色；
- 它负责机体的「休息和消化」功能，如促进能量储存、减慢心跳、降低心肌收缩力等；
- 副交感神经激活，会使 HRV 升高。
当你吸气时，交感神经略微活跃，心率加快；当你呼气时，副交感神经占上风，心率减慢。这种随呼吸而变化的心率波动，医学上称为「呼吸性窦性心律不齐」，它是 HRV 的重要组成部分。一个健康的自主神经系统就应该是灵活的：该紧张时能迅速调整状态，迎接挑战；该放松时也能快速冷静下来。这种「一张一弛」的能力，就体现在 HRV 的数值上。
HRV 的测量和计算
那么，从这些跳动的数字到一个具体的 HRV 值，是怎么计算出来的呢?
首先，记录设备需要捕捉每一次心跳的精确时刻。医学上的金标准是心电图，它记录心脏每次跳动时产生的电信号，在心电图上，每次心跳都表现为一个尖峰，称为「R 波」。两个连续 R 波之间的时间间隔，就是我们要测量的「RR 间期」。现在还有相对便携的心电图设备，可以让患者 24h 佩戴，来获得患者连续的、24h 的心电图数据。
消费级设备使用的是另外一种技术——光电容积脉搏波（PPG）。你手腕上那个绿光 LED，实际上是在通过检测血液流动引起的光吸收变化来推算心跳。这种方法的原理是：心脏每跳动一次，就会有一个血流脉冲传到手腕，LED 发出的光被血液吸收的程度就会发生微小变化。通过检测这些变化，设备可以推算出每次心跳的时刻，从而记录下心跳的间隔数据。
拿到这串心跳间隔数据后，需要先识别异常搏动、漏搏和伪影，得到适合分析的正常搏动间期；再通过不同的算法得出不同的 HRV 数字。
HRV 的计算方法主要分为三大类：时域分析、频域分析和非线性分析。
了解过一些数据科学的读者就会看出来，非线性分析是一个非常抽象的方法，计算和解释起来非常复杂。并没有成熟的算法，更多地用来科研探索，作为应用来说并不合适。
频域分析对数据的精确度和连续性要求较高，而 PPG 技术很容易受到干扰。如手臂晃动、传感器接触不良、皮肤颜色深浅、纹身、温度变化等都会影响测量的精度。最终导致整个频谱计算出来的结果就会完全失真，没有任何参考价值。而且，关于 LF 和 HF 值，学术界一直存在争议，尚无定论。
所以，消费级产品中（智能手表、手环、戒指等）基本都是使用时域分析法，它计算简单、结果直观。其中，最常见的两种算法是 SDNN 和 RMSSD。
有趣的是，我手上的两个设备，正好用的就是这两种不同的算法。Apple Watch Series 10 使用的是 SDNN，而 Oura Ring 4 使用的是 RMSSD。那么这两者又有什么不同呢？
SDNN 和 RMSSD
SDNN（Standard Deviation of Normal-to-Normal intervals）
SDNN 是最经典的心率变异性指标，前文提到的 808 名心肌梗死患者研究正是采用这一方法。它的计算很直接：对所有正常心跳间隔求标准差。
以 5 个心跳为例（实际应用中通常需要 24 小时或至少 5 分钟的数据），假设间隔分别为 950、1030、980、1040、960 毫秒，均值为 992 毫秒。依样本标准差公式，将每个数值与均值的差平方后求和，再除以（N-1）并开方，得到 SDNN 约为 41 毫秒。
大量研究已证实，SDNN 与冠心病、房颤、心肌缺血、心衰等多种心脏疾病密切相关。在预后研究中，它也被视为预测心血管死亡率（因为心血管疾病导致的死亡）和全因死亡率的可靠指标。
但 SDNN 有一个明显的局限：心率本身的变化会干扰结果。比如你从床上起来开始运动，5 分钟内心率从 60 次/分钟升至 100 次/分钟。即使每次心跳的间隔都非常均匀（变异性很低），但由于整体均值发生了偏移（心跳越快，心跳间隔越短），计算出的 SDNN 会明显偏高。
因此，SDNN 更适合反映一段时间内的总体波动，而非瞬时状态。旧款 Apple Watch 的采样方式就是每隔一段时间采样一次（每次约 1 分钟），如实记录下来。然后计算这些采样点的日、周、月均值，最终以「趋势」的形式呈现——作为一段时间内心脏健康的一个参考指标，而非单次精确的评估。
RMSSD（Root Mean Square of Successive Differences）
RMSSD 则不同，它的关键在于「相邻」。它不看所有间隔的整体分布，而是聚焦于相邻两次心跳之间的差异。
还是以刚才那组数据为例。我们计算相邻差值：(1030-950)、(980-1030)、(1040-980)、(960-1040)，得到 80、-50、60、-80 毫秒。把这些差值平方、求均值、开方，得到 RMSSD 约为 69 毫秒。
因为只看相邻差值，RMSSD 几乎不受心率趋势变化的影响。同时，这种计算方式的独特魅力在于，它能够反映副交感神经活动，特别是迷走神经的激活。生理学上，副交感神经的信号传递非常快（毫秒级），能让心跳立刻减慢；而交感神经依赖化学传递，响应较慢（秒级）。因此，相邻心跳之间的快速波动，恰恰是副交感神经活性的体现。RMSSD 正是捕捉这种高频变化的理想指标。
RMSSD 越高，说明副交感神经越活跃，身体越放松。注重睡眠监测的 Oura 采样频率较高，会记录整晚的睡眠数据（如果你留意观察，睡觉时 Oura Ring 的绿色 LED 几乎一直亮着）。当你醒来，就能得到整晚 RMSSD 的加权平均值，作为睡眠质量和身体恢复水平的重要参考。
值得一提的是，Apple Watch 其实也会记录原始心跳数据。许多第三方 App（如 Athlytic、PeakWatch 等）正是读取这些数据来计算 RMSSD，从而实现类似 Oura 的恢复评分功能。而最新的 Apple Watch Series 12 与 Ultra 4 配备了全新的光学和电极式心率传感器，后台心率读取频率较旧款提升至 60 倍，心率变异率的测量频率提升 24 倍，于是在健康 app 也加入了对数据频率要求更高的「恢复心率变异率」数据，其正是采用 RMSSD 方法测算。
HRV 的消费者手册
对于大多数你我这样的普通消费者而言，我们其实并不关心 HRV 是如何算出来的，我们更关心的是以下两个核心问题：
- HRV 数据的实际价值：它能反映哪些健康/生理指标，科学证据有多强；
- 消费级设备的 HRV 准确性：Apple Watch、Oura Ring 以及其他主流可穿戴设备的测量精度如何，与医疗级设备相比差距多大；
HRV 数据的实际价值
研究表明，HRV 是一个敏感但非特异性的生物标志物。简单来说，它能告诉你「身体出问题了」，但它无法准确地告诉你「具体出了什么问题」。
疾病监测与预警
目前最有力的证据来自疾病监测领域。2022 年一项 meta 分析显示，HRV 处于最低四分位数的人群，全因死亡风险是其他人群的 1.56 倍。另一项针对无心血管疾病人群的 meta 分析发现，较低的 HRV 与首次心血管事件风险增加 32%–45% 相关；SDNN 每提升 1%，致死性或非致死性心血管疾病风险约降低 1%。
心理健康方面，研究一致显示抑郁、焦虑乃至双相障碍、精神分裂症患者的 HRV 均明显降低。基于 HRV 的生物反馈训练（即实时监测 HRV 并通过呼吸调节将其调整至良好状态）已被证明能显著改善焦虑和抑郁症状，尽管长期临床效果仍需更多研究验证。
此外，一项基于智能可穿戴设备的 meta 分析显示，新冠肺炎患者的 SDNN 和 RMSSD 均出现下降，分别降低约 3.25 毫秒和 1.24 毫秒。
运动训练与生活方式反馈
多项对照研究表明，HRV 导向训练能有效提升运动表现和训练效果，并降低不适感。这种方法根据每日晨起 HRV 动态调整训练计划：当 HRV 处于基线或升高时进行高强度训练，显著低于基线时则安排低强度训练或休息。但需注意，现有研究普遍样本量较小、方法学差异大，尚缺乏标准化。
在生活方式方面，酒精是副交感神经的强效抑制剂，即便少量晚间饮酒也会导致当晚睡眠期间 HRV 显著降低。深夜进食、失眠、作息紊乱同样会直接反映在次日的 HRV 数值上。不过，慢性失眠与 HRV 之间的关联目前尚不稳定。
因此，如果你某天早上起来，发现自己的 HRV 值降低了，这确实意味着身体存在某种应激。可能是熬夜了、喝酒了、前一天健身得有点猛，也有可能是要感冒了，心脏出毛病了，血糖不稳定等等。
综上所述，HRV 本身无法诊断具体疾病，但它是一个极具价值的纵向健康追踪工具。其核心价值在于建立个人基线，通过观察偏离基线的趋势来指导生活方式调整。对于追求健康优化、疾病早期预警或科学训练的人来说，持续追踪 HRV 具有一定的实用价值。
但如果试图依靠短期数据波动，或者某个固定标准（比如高于或低于某个特定数值）来判断压力水平或诊断疾病，我对此持保留态度。目前也没有足够的证据，或者指南文件支持这样做。
消费级设备的 HRV 准确性
前文提到的研究大多是基于心电图测量 HRV 的。心电图是医学上测量、计算 HRV 的「金标准」。它通过皮肤电极直接捕捉心脏去极化产生的电信号，精度极高且抗干扰能力强。
而消费级设备几乎都是采用前文提到的 PPG 技术。这种光学方法实际测量的是脉搏率变异性（PRV），即血管容积变化产生的脉搏波间隔，而非真正的心率变异性。脉搏波从心脏传导至外周传感器需要时间，而这个传导时间会受血压、动脉硬化程度和年龄影响，从根源上造成 PRV 与 HRV 的差异。同时，PPG 抗干扰能力较弱，高度依赖测量条件。
好消息是，在夜间睡眠或静息状态下，PPG 与心电图的一致性可达优秀水平，相关系数在 0.91 至 0.999 之间（越接近 1 越好）。2025 年一项最新研究对多款消费级可穿戴设备的夜间静息心率和 HRV 准确性进行了验证，排名如下：Oura Gen 4 > Oura Gen 3 ≈ WHOOP 4.0 ≈ Garmin Fenix 6 > Polar Grit X Pro。

10 月初，广东国际赛车场，绿醇超吉联赛 PRO 第二回合。高翔前一天刚从杆位起步一路领跑拿下冠军，但第二回合最后几圈，他和李家禧在八号弯前发生碰撞，赛会红旗。几天后他在微博写道：
时速大约一百五，后背断了三根肋骨，今年退出赛车。
150 公里每小时放在赛道上不算快，但撞上就是大伤。并且这已经是这一个多月里国内赛道上第二起让人揪心的事故：9 月 5 日，China GT 上海站 GT3 组正赛第 7 圈，33 号宝马和 37 号法拉利争位时接触，双双失控滑向 T14 发卡弯，37 号从侧面撞上了正在弯心过弯的 91 号法拉利 296 GT3。事发时车群刚从全场最长的大直道末端重刹入弯，碰撞速度接近 270 公里每小时。91 号当场起火，英国车手奥利·米尔罗伊（Ollie Millroy）被困在座舱里。
接下来的一分钟里，开着 79 号保时捷的 23 岁荷兰车手卢克·哈托格（Loek Hartog）把车刹停在火场边，弃赛跳下车，接过赛道工作人员递来的灭火器冲进火里，把已经昏迷的米尔罗伊从座舱里拖了出来。从哈托格停车到米尔罗伊脱困，59 秒。
事后公布的官方监控时间轴里，则记录着另一组数字：
- 撞车起火后的第 4 分 08 秒，赛会首席医疗官与医疗车才赶到现场；
- 第 6 分 16 秒，第一辆救护车才停在事故点旁。
米尔罗伊被送往瑞金医院北院，右侧肋骨断了 6 根，锁骨和手部多处骨折，右肺被刺穿，一周后 CT 又查出一处颈椎微小骨裂。他完全记不起撞车前 30 秒到事发后一小时的事。住院两周后出院。
后来披露的伤情里有一个细节：他头盔的面罩碎了，颈部的 HANS 也断了。
HANS 是头颈支撑系统（Head and Neck Support），一件挂在车手肩膀和头盔之间的碳纤维护具，后面细讲。车都撞得四分五裂了，连碳纤维护具都拉断了，人却活着出了院——平时不怎么看赛车的朋友刷到这类事故视频，最常冒出来的问题大概是：
车都撞成废铁了，人为什么还能活？
一场「四棒接力」
把米尔罗伊这场事故从撞击到脱困拆开看，现代赛车的保命机制是一场「四棒接力」：
- 车体先碎，替人卸力
- HANS 拉住头颈
- Halo 罩住头顶
- 赛道上的人在几十秒内把车手接走
这里面藏着两个事实：要保住车手，赛车和护具得先替他碎掉；而这些保命的装备刚问世时，几乎被整个圈子嫌弃过。
第一棒：为什么保命的第一步，是让赛车替你粉身碎骨？
直觉上不少人会觉得赛车安全意味着车身够结实，比如买家用车看防撞梁厚不厚、气囊有几个，很容易以为赛车就是把钢梁换成更贵的碳纤维，再在车里焊一圈防滚架 （马路上也总有人觉得车皮够厚就能撞赢水泥墩子）。在家跑模拟赛车时关掉车损，250 公里每小时贴着墙刷圈也没事。
可在真实世界里，把赛车做成撞不坏的铁疙瘩，对车手反而最危险。道理和从高处往下跳差不多，腿绷直了硬砸地面，冲击顺着脚踝一路传上来；顺势屈膝蹲下去，把「停住」这件事拉长一点，膝盖和肌肉就把劲卸掉了。
赛车撞墙干的是同一件事——泄力（接化发）。撞上去之前车有多快，改不了了，能改的只有从冲击到停止花了多长时间。这段时间越短，座舱里的人挨得就越狠，所以工程师宁可让车头、悬挂、外壳先碎先飞，也要给座舱多抢出一点缓冲。反过来，如果整台车撞上去纹丝不动，车手体内的器官和大脑照样会因为惯性狠狠撞上体腔壁——就像一杯没盖盖子的奶茶，杯子停了，里面的液体还在往前冲。
所以第一棒就一句话：外围负责碎，座舱负责不塌。
上海站的 91 号法拉利 296 GT3 就是这么做的。侧撞之后，车体外壳、悬挂、轮毂几乎全被撞飞撞碎，替车手消耗掉了大量的撞击动能；包裹车手的座舱和防滚架死死挺住，没有向内压到他的身体。米尔罗伊在病床上等手术时写了一句：
感谢法拉利造出了一台能经受住这种撞击的赛车。
把「车碎人活」展示得最直观的，其实是 2020 年 F1 巴林大奖赛：格罗斯让（Romain Grosjean）的哈斯赛车在正赛第 1 圈和后车擦碰后失控，以 192 公里每小时、29 度角撞向赛道边的三层金属护栏，峰值加速度 67G。
撞击末段，后半截几百公斤的动力单元和前面的碳纤维生存舱断裂分离——当时媒体惊呼「赛车被斩成两截」，但在工程上，这几百公斤带着惯性飞走，恰恰避免了全部质量继续挤压前舱；与此同时，车头的碳纤维前碰撞结构像手风琴一样逐级压溃，把「从撞上到停住」的过程拉长了一截，让传进生存舱的冲击落在了人体还能扛住的范围。
车壳碎了、座舱保住了，六点式安全带把车手死死按在座椅上——但身上还有两个地方没被护住：一个是被惯性往前甩的脖子，一个是暴露在座舱上方的头顶。
第二棒
六点式安全带像铁钳一样把躯干按在座椅靠背上，车正面撞停时胸口和腹部都被拉住了。
但脑袋没有被绑住。
在没有 HANS 的年代，赛车手最怕的一种伤叫颅底骨折。车手头上顶着一公斤多的头盔，在惯性作用下继续往前甩，所有的减速拉力瞬间落在了脖子上。而拉力一旦超过颈部极限，颅骨底部会被硬生生扯断。当年这种伤几乎没有生还的可能。
1994 年的伊莫拉赛道，大家记住的是车神塞纳的陨落。可就在塞纳出事的前一天排位赛里，奥地利年轻车手罗兰·拉岑伯格（Roland Ratzenberger）以 314 公里每小时撞墙身亡，死因正是颅底骨折。
事实上，拉岑伯格出事的 9 年前「解药」已经做出来了。1981 年美国车手吉姆·唐宁（Jim Downing）的队友帕特里克·雅克马尔（Patrick Jacquemart）在测试中死于同样的伤，唐宁找到自己的姻亲——密歇根州立大学的生物力学教授罗伯特·哈伯德（Robert Hubbard），两人开始研发头颈保护装置，1985 年做出了 HANS 的第一台原型。
HANS 的结构说穿了很简单：一个 U 形碳纤维肩托压在安全带下面，两根织带从肩托伸出来扣在头盔两侧。撞击时头往前甩，织带瞬间绷直，把冲力通过肩托传到双肩和躯干上。原本由脖子独自硬扛的拉力，被分给了更结实的身体。
就是这么一件能救命的东西，问世后被嫌弃了整整十年。唐宁和哈伯德四处找安全装备厂商谈量产，几乎全被拒绝。唐宁后来接受美联社采访时回忆，1991 年开卖后的十年里一共只卖出 250 套，拒绝的理由听了个遍：「这玩意儿像个马桶圈」「戴上它脖子都转不了，没法看后视镜」「真正的车手不需要这个」……
直到 1994 年塞纳和拉岑伯格接连殒命，HANS 才被认真摆上台面上，9 年后，2003 年 F1 正式强制所有车手佩戴。
第三棒
天上飞来一台失控的赛车，迎面切过来一道护栏，或者翻车时头顶的防滚架自己先断了——怎么办？
被嫌弃的剧本在 Halo 身上又演了一遍。2018 年，FIA 强制在 F1 座舱上方加装一个五级钛合金三叉形防护架，车迷给它起了个外号叫「人字拖」。开轮赛车几十年来一直是优雅的开放式座舱，车手的头盔直接露在空气中。FIA 要在这片干净的空间上面焊一个裸重 7 公斤的钛合金架子，整个舆论场几乎炸了锅。
车迷骂它毁了开轮赛车的美学传承，车手也不买账。比如当时担任车手协会董事的格罗斯让公开反对，说宣布引入 Halo 的那天是「F1 悲伤的一天」；哈斯车手马格努森更直白，说「如果它看起来像坨垃圾，那它就是坨垃圾」；三届世界冠军尼基·劳达说 Halo 毁掉了 F1 赛车的 DNA；梅赛德斯领队托托·沃尔夫在 2018 年新车发布会上的原话则是：「如果可以的话，我真想拿把电锯把它锯掉。」
10 支车队里据报道有 9 支投了反对票，但 FIA 还是把它硬塞进了 2018 赛季的技术规则。接下来四年里，它接连完成了三次救命实战。
2018 年 8 月 F1 比利时斯帕站，起步一号弯多车连撞，阿隆索的迈凯伦被铲飞，整台车连着右前轮砸向索伯车手夏尔·勒克莱尔（Charles Leclerc）的座舱。阿隆索的前悬挂当场折断，勒克莱尔头顶那根被骂了大半年的 Halo 上留下一道黑色轮胎擦痕，FIA 估算峰值载荷约 58 kN（大约相当于 6 吨重物压在上面）。勒克莱尔赛后承认：「我从来都不是 Halo 的粉丝，但今天看到它挡在我头上，我真的太高兴了。」
两年后的巴林站，Halo 又救了一次人——而且救的是当初反对它的人。还是格罗斯让那场 192 公里每小时的撞击。生存舱护住了他的身体，但上层钢制护栏正对着他敞开的座舱。1974 年美国大奖赛上，25 岁的奥地利车手赫尔穆特·科尼格（Helmut Koinigg）就是在几乎一模一样的护栏穿透事故中当场丧生的。46 年后，格罗斯让头顶的钛合金 Halo 把上层护栏硬生生顶开，给他的头部撑出了一块空间。撞车后第 27 秒，他自己解开安全带从火里跳了出来。
当天晚上，这位当年反对 Halo 的车手协会董事举着缠满绷带的双手，在病床上录了一段视频：
几年前我反对 Halo，但现在我认为这是我们为 F1 带来过的最伟大的东西。没有它，我今天不可能在这里和你们说话。
如果说前两次是 Halo 的本职工作——挡飞来的重物和护栏——那 2022 年银石站的这一次，展示的是安全设计里一个更狠的原则：冗余。这次周冠宇的赛车在发车阶段被撞翻，底朝天滑出去。
按设计，座舱后上方那根高高竖起的防滚架（roll hoop）负责在翻车时撑住车身，给头盔留出空间。然而赛车倒扣砸向地面时，防滚架的尖顶扎进了沥青路面，巨大的撕扯力直接把它整根削断了。
换作 2018 年之前，这意味着车手的头盔要直接以接近 200 公里每小时的速度贴着地面硬磨，但防滚架断掉的那一秒，前方的 Halo 作为第二道防线顶了上来，撑住了头盔和地面之间那几厘米的净空，一路擦着火花滑过砂石区、翻过轮胎墙。
周冠宇被送进医疗中心检查后，自己走了出来。
FIA 很快打了补丁：从 2023 年起强制防滚架顶端改成圆顶，不容易扎进路面，同时提高了载荷测试标准。
第四棒
我们把前三棒和最后一棒放在一起看：
不难发现，前三棒再贵，也只管撞上去的那一瞬间。车一停稳，硬件的活就干完了。燃油管路可能已经破裂，火可能已经烧起来，车手可能已经昏迷，如果是 6 根肋骨刺破了右肺、HANS 断了的情况，车手根本不可能像格罗斯让那样 27 秒内自己跳车。
防火层和赛车服能挡一阵高温，车载灭火系统能压一阵火，但它们买来的只预留了几十秒的倒计时。这几十秒里没人把车手接走，前三棒保下来的人照样可能留在火里。
这正是上海站最让人后怕的地方。哈托格 59 秒把米尔罗伊拖出火海——这是一位对手赌上自己比赛的义举。同场参加 GTS 组的吴彦祖赛后发视频批评：赛会在事故发生 36 小时后才有表态，「这太丢人了……那一整套系统彻底失效了。」91 号所属的 FIST Team AAI、33 号所属的 TBC by 610Racing 等多支车队随后相继退出 China GT。
把日历往前翻 50 年。1976 年 8 月，德国纽博格林北环，22.8 公里的「绿色地狱」根本没法做到消防全覆盖；卫冕冠军尼基·劳达的法拉利撞墙弹回赛道中央起火，他被卡在了近 800°C 的烈火中。把他拖出来的，是紧跟着停车的四位对手——盖伊·爱德华兹（Guy Edwards）、阿图罗·梅尔扎里奥（Arturo Merzario）、布雷特·伦格尔（Brett Lunger）和哈拉尔德·埃特尔（Harald Ertl），梅尔扎里奥把手伸进座舱解开变形的安全带，和伦格尔合力把重度烧伤的劳达拖了出来。次日英国《卫报》写了一句：他「肯定是靠其他车手才活了下来」。
50 年了，赛车有了碳纤维生存舱，普及了 HANS，装上了 Halo，可 2026 年在上海，第一个把车手从着火的座舱里拖出来的，还是一位停下赛车的对手。
可见装备越强，主办方越容易滑进一种惰性：规则里写满了强制购买的顶级护具，消防布点和医疗调度就可以松口气。但账很好算，护具负责买时间，救援体系才是真正负责救命的那一个。买来的时间没有被体系兜底，危险只是往后推了几十秒。
装备能买到，但体系买不到
顶级赛事的安全补丁早就不只打在车身上了。
2014 年日本铃鹿站，儒勒·比安奇（Jules Bianchi）在大雨中冲出赛道撞上正在缓冲区吊运事故车的工程吊车，并于九个月后离世。这起事故直接催生了我们在上一篇聊过的虚拟安全车（Virtual Safety Car, VSC）。
FIA 2026 赛季的新技术规则也在继续补洞：前鼻锥吸能结构改为两级分离设计，第一次撞击鼻锥脱落后，面对二次撞击座舱前方仍有缓冲；座舱两侧抗侵入载荷要求继续提高；极端恶劣天气下新增侧向高亮度闪烁警示灯，让后方来车在水雾中第一眼看清横在赛道中央的事故车。
这两年国内汽车运动升温也很快，2026 年 6 月商务部等 9 部门印发《关于培育壮大汽车后市场消费若干措施的通知》（商消费函〔2026〕145 号）里专门点了「提升安全办赛能力水平，强化办赛标准流程」。
很多赛事主办方以为，把赛道租下来、拉满赞助商横幅、请来最昂贵的 GT3 甚至方程式赛车，就是办好了一场高级别比赛。但现实给所有人上了一堂沉重的课：最顶级的法拉利赛车、最高规格的碳纤维单体壳、最先进的 HANS 和防火服，车队只要花钱就能买到；但事故发生时秒表倒数下的指挥中枢、受过严格实战演练的马修团队、几十秒内抵达现场的急救医疗组，是用钱买不来的。它需要成百上千次的应急演练，需要对赛道上每一面旗语、每一台吊车、每一个灭火器保险销的极度较真，需要主办方对车手生命发自内心的敬畏。
当你下次在屏幕前看到两台赛车撞得粉身碎骨、而车手淡定地推开残骸向看台挥手致意时，希望你能想起今天的故事——因为这绝对不是什么「上天眷顾」的奇迹，每一次车手生还的背后，都是几十年前顶着骂声立项的工程师、替肉体粉身碎骨的溃缩部件，以及在浓烟烈火中读秒狂奔的救援体系，在生死窗口里，联手赢下的又一场硬仗。

And until now, no treatment could restore their vision. The PRIMA system, which was approved in Europe in July and is awaiting FDA clearance in the US, changes that. It combines a retinal implant with camera-equipped eyeglasses to improve sight in patients who develop a blind spot in the middle of their vision due to advanced AMD. Developed by the California-based Science Corporation, the system takes advantage of the fact that AMD doesn’t damage all retinal circuitry; only photoreceptors—the cells that convert light into an electrical signal—die off. PRIMA’s implant mimics those cells and transmits visual information directly to healthy eye circuitry and on to the brain. “We’re leveraging all of the body’s own natural functions to process and transmit the information,” says Frank Brodie, an ophthalmologist at the University of California, San Francisco, and Science Corp.'s chief medical officer for ophthalmology.
CAPTURE
Glasses outfitted with a miniature front-facing camera capture what someone is seeing in real time. The video feed is roughly five megapixels running at 30 frames per second, which is similar to TV. The raw video is transmitted to a connected processor via a fiber-optic cable.
CONVERT
A small, handheld processor, which can be set on a table or tucked in a pocket, converts the video feed into infrared light signals that route back to the glasses. The device also includes physical buttons that let the wearer adjust contrast, brightness, and zoom.
DISPLAY
A laser projector on the glasses faces the wearer and shines pulses of near-infrared light directly at the eye at 880 nanometers—an invisible wavelength. This signal passes through the pupil and on to the retinal implant in the back of the eye.

The implant is made up of 378 pixels, each with an electrode and two photovoltaic cells, which do double duty. They convert the light into a current that healthy bipolar and ganglion cells pass on to the brain. They also act as solar cells to power the chip, eliminating the need for a battery.

There’s even a company focused on longevity medicines for domesticated cats.
I don’t know how or when Peppy died. But if there had been a drug that might have protected her from diabetes or arthritis, there’s no doubt I would have tried to get my hands on it.
That’s about where my enthusiasm for pet life extension ends, though.
I’m far less interested in cloning, a relatively new option for people mourning a pet and seeking a replacement. In most cases, this technology involves taking the DNA of a pet, putting it into an egg cell from another animal of the same species, and growing the resulting embryo in a surrogate animal. It worked for Dolly the sheep, who was born the year before Peppy went missing. It has since worked for other mammals, including cattle, horses, and ferrets—and cats and dogs. In the US, a company called Viagen Pets offers to clone cats and dogs for $50,000 a go. This doesn’t result in an exact replica of the animal but a genetic twin.
Still, there are lots of reasons why a person might want to clone a pet. On its website, Viagen explicitly offers customers “a way to hold on.” Lori Kogan, a professor of clinical sciences at Colorado State University who has studied human-animal relationships for decades, doesn’t have a problem with the practice. She points out that while we have well-established rituals for coping with the loss of a person—such as funeral services, time off work, and memorial gifts—we don’t really have the same for pets. As a result, pet owners can experience what is sometimes called “disenfranchised grief,” she says. Having their feelings go unrecognized can feel isolating. If cloning a pet brings a person peace, she says, “who are we to judge?”
Fair enough. But I can’t help thinking that pet loss in childhood might be different. It’s often the first time a child confronts death. Losing Peppy was a formative experience, and distressing though it was, I like to think it helped prepare me for losses I experienced in adulthood. I wouldn’t want my own children to think that death is not final, and that individuals can be replicated or replaced.
Or, for that matter, revived, which is the promise behind pet cryonics. For a fee, a handful of companies offer to cool dead pets to extremely low temperatures and store them for long periods of time—even indefinitely. The idea is that at some point in the future, we’ll have invented incredible technologies that will not only bring your pet back to life but also cure whatever it died of. Alcor, a cryonics facility in Arizona, is currently storing the remains of hundreds of pets as well as people. It even recently announced it had cooled a small marsupial—its first pet sugar glider.
With cryonics, the chances of being reunited with your pet are bordering on zero. Even those who work in the field acknowledge that the stored people and animals are unlikely to be reanimated. As things stand, there is no way to really and truly bring any animal “back.”
I miss Peppy. But given the chance, would I stick her in a vat of liquid nitrogen? Or get another cat to give birth to a genetically identical animal? No, I would not.
RIP to the one and only Peppy.

I vividly remember the first time I read one of Francis Halzen’s papers about high-energy neutrinos. It was the late 1990s, and I was an undergraduate student at the University of California, Berkeley. The field of astroparticle physics was young, and Halzen was making predictions that couldn’t be tested using conventional particle accelerators.
On 6 October, Halzen was awarded the Nobel Prize in Physics for his work on the IceCube Neutrino Observatory at the South Pole. The experiment uses sensors embedded in the ice to detect high-energy neutrinos (a type of fundamental particle) that have been blasted towards Earth from distant cosmic accelerators.
Astroparticle physicists have lots of ideas for experiments that have the same discovery potential as IceCube. For example, the underwater Pacific Ocean Neutrino Experiment (P-ONE) — a collaboration between North America and Europe — is currently under construction off the coast of Vancouver Island, Canada. There are also several projects searching for dark matter (a substance that does not interact with or emit light), including the XLZD Collaboration (a European–North American consortium) and PandaX in China.
However, realizing these experiments is not easy. The story of Halzen and IceCube is a lesson not just about fundamental science, but also about what it will take to build the infrastructure that will support discoveries over the next few decades.
When I first read Halzen’s paper (F. Halzen etal. Astrophys. The construction of AMANDA cost around US$7 million. This is much less than the $271 million it cost to build IceCube. Nevertheless, realizing experiments at this smaller scale can be difficult. They require more resources than an initial proof-of-concept project, but they are not large enough to make a discovery.
Many countries face difficult decisions about research funding, and I am concerned that small and mid-scale projects could be an easy target for cuts.
