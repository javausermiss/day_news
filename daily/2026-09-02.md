The .NET patcher modifies files in the selected local Wand installation and does not contact an update or telemetry service. The bundled version.dll proxy is loaded by Wand and changes Electron's ASAR-integrity fuse byte inside Wand's own process; it does not inject into another process. Wand itself remains an online application, build tools restore declared dependencies, and the optional Remote Web Panel deliberately starts a LAN HTTP/WebSocket server and uses Wand API/CDN data. Review the source and build the executable from your own fork; unsigned patching tools can trigger generic antivirus heuristics.

WandEnhancer includes a built-in Remote Web Panel allowing you to control app features directly from your phone.
- Ensure both your PC and phone are on the same Wi-Fi network.

- Page isn't loading? First, ensure both your PC and phone are connected to the same local network. Some routers and guest Wi-Fi networks enable client isolation/AP isolation, which blocks devices on the same SSID from reaching each other. If it still does not load, check Windows Firewall and allow inbound traffic on TCP port 3223 for your local network. If Windows marked your connection as Public, switching it to Private can also help.
- Using mobile data or a different network? If you want to use the panel over mobile data (LTE/5G) or from an entirely different network, you can use Tailscale or similar VPN tools.
- The panel uses plain HTTP on port 3223 and has no pairing code. Anyone who can reach that port can view the panel and control the active trainer, so use it only on a trusted LAN/VPN and never expose the port directly to the internet.
- The panel protocol does not include your Wand bearer token or installation-path fields.

You can inject your own JavaScript into Wand at patch time to tweak or fix things in the client UI. This reuses the same renderer injection the Remote Web Panel uses, so it requires the Remote Web Panel patch to be enabled.
How to add a script
- In the patch dialog, add one or more .js files (only existing.js files are accepted), or

How it runs
- Each script runs inside Wand's renderer (full DOM access, plus Node require ).

To be clear, long-distance optical audio pickup is real: if you shine a laser at a pane of glass or other reflective surface, sound-induced vibrations can be picked up by measuring the angle of the reflected beam; in favorable conditions, this supposedly works at distances in excess of 100 m (330 ft). When you think about it, there are some red flags. First, the gas in the tube is kept at about 1/200th of atmospheric pressure. It’s nearly vacuum — not exactly a good medium for sound waves. Second, the glowing gas emits UV, which needs to be converted to visible light using an opaque phosphor layer that covers the inside of the tube and exhibits strong afterglow. Wouldn’t that coating mask any momentary, localized changes in luminosity?…

上一次为大家整理官翻购买渠道已是两年前，不知道在缺席的这一年里，你是否买到了心仪的设备？如今又逢开学季，不妨再来看一下有官方质保背书、经过原厂翻新的官翻与认证二手产品又有哪些新选择。
这一季的官翻市场可以说是亮点颇多，除了「老朋友们」的常规更新，还有一些之前没见过的官翻新面孔，无论是开学添置生产力工具，还是给家里添置日常工具，相信都能在这些靠谱的渠道里帮你省下一笔开销。

购买时请认准店铺资质和授权，具体产品的成色和质保政策请咨询销售渠道。价格可能因优惠券、促销等原因有所差异，选购时请以实时价格为准。

手机数码类
Apple
- Apple 认证的翻新产品：Apple 官方网站
无论是新技术推广，还是官翻产品销售，Apple 依然是主力标杆。有关于 Apple 官翻产品的政策大家可以去往期文章中了解一下，我们直接来看今年在售产品。
目前 Apple 在售官翻产品线包括 Mac、iPad、Apple Watch、AirPods、HomePod，另外分类中显示的「配件」其实只有 Apple Pencil、HomePod 和显示器产品，大家在各主产品线中都能看到。
其中 Mac 依然是 Apple 官翻库存最稳定、选择最丰富的一条线。除了搭载 M4、M5 系列芯片的官翻 MacBook Air 与 MacBook Pro 纳入销售范围之外，我们也能看到 2026 年 3 月新发布的 MacBook Neo 在可选之列。
同样是 8G 内存和 256G 存储容量的规格，官翻机售价 4699 元，相比同款全新机 5499 元依然保持着 85 折的力度，附带电源适配器和线缆，支持一年质保且可选 Apple Care+。配备 M5 芯片、16G 内存、512G 存储的 MacBook Pro 官翻机售价 11499，同样是 85 折左右的力度。
年初因为 OpenClaw 大火的 Mac mini，16+512 的 M4 版官翻售价 6399；另外还有新发布的 Studio Display 显示器设备可供选择。
Apple 在 iPad 产品线上依然保持着「官翻不与在售商品竞争的原则」，所以我们没有看到最新款搭载 M5 系列的官翻机，货源主要还是搭载 M4 及其前代芯片的早期产品（甚至还有 A15 的 iPad mini 6）。
Apple Watch 产品线则好一些，最新款 Series 11 和 SE 3 这两个系列都有对应官翻产品，亮黑色铝合金 42mm 的 GPS 版官翻售价 2499 元，约为 83 折左右。不过智能手表与普通手表不同，它会更多参与到用户的运动过程中。如果你没有洁癖并且相信 Apple 翻新把控，那么这种折扣力度还是不错的。
AirPods 本身目前是没有可选的官翻产品，HomePod 也依然只有第二代黑白两色可选。除此之外，官翻 iPhone 仍没有在中国大陆地区上架，如果大家在第三方平台看到打着「Apple 官方认证」旗号的翻新 iPhone，请务必留意。
三星
- 三星官翻机：微信公众号「三星官翻机」，或在京东、淘宝、抖音商城搜索「三星 官翻」
三星绝大部分业务已经退出了中国市场，不过手机业务目前势头还不错，我身边已经有不少用其他品牌手机的朋友换成了三星折叠屏。相比往年，三星手机现在的官翻产品销售渠道拓宽了不少，除了依然活跃的公众号店铺和京东、淘宝的销售渠道外，在抖音里也能搜到相关店铺。
今年三星手机官翻产品线基本维持着与新品一致的更新步调，比如超大杯 S26 Ultra，公众号店铺 12+256 的准新成色 7 天机售价 7199 元，官方商城售价 9999 元，京东自营店铺售价 9499 元。官翻店铺的折扣力度确实诱人，而且这里还可以买到官方商城限定色。
折叠屏方面，新发布的 Z Fold 8 目前还没有上架，前代产品 Z Fold 7 的 7 天机 12+256 版，公众号店铺官翻售价 9199 元，官方商城售价 13999 元，京东自营店铺售价 11499 元。这款机型的折扣力度就没有想象中那么大，喜欢折叠屏的朋友或许可以等到 Z Fold 8 官翻机上架后再来看看前代产品是否会降价。
值得一提的是，虽然我们在各大电商平台能搜到很多家三星官翻店铺，但背后大多是由三星老牌合作伙伴「图腾」在统一运营。平时大家买三星新机附赠的碎屏险、换电池等服务，基本也是由这家公司提供。所以在这类官翻店铺下单，往往同样能享受到免费赠送的增值权益，算下来不仅便宜，售后保障也足够让人放心。
华为
上一次提到华为官方翻新专区的入口被隐藏了，不过今年在 VMALL 商城里我们可以在手机分类下看到「华为官方翻新」入口又回来了，可选商品一直在更新中，而且在京东还有授权商家开设了官翻机专卖店。
根据最新的介绍，华为官翻机主要是以 99 新的 7 天机为主，若产品需拆机更换零部件，则确保使用原厂物料。同时在官方商城购买的官翻机支持 7 天无理由退货、15 天质量问题换货和一年质保服务。
价格方面，三折叠机 Mate XT 的黑色 16+512 规格的全新产品官方售价 19999 元，官翻售价 14999 元。同款官翻机在京东拍拍二手价格大约在 9000 元左右，但成色描述逊于官翻机。对于三折叠这类高价值产品，还是官翻机更可靠一些。
直板机 Pura 80 Ultra 的价格体系很有趣。其中金色 16+512 版官翻售价 5999 元，商城全新售价 9999 元并赠送液冷手机壳和 FreeBuds 降噪耳机，两款赠品总价值在 300 元左右，而京东自营商城的全新机虽然无赠品，售价却只有 5514 元。
虽说该型号是上代产品，但官翻机比电商平台全新机还要贵，确实不太多见。
荣耀
- 荣耀官方翻新机：荣耀商城官方翻新专区
荣耀手机最近凭借自带云台可谓是出了一次圈。在官翻产品上，荣耀似乎要更重视一些，不仅所示产品均为有货状态，而且在商城 banner 滚动的最后一页还宣传着翻新机专区。
荣耀官翻机的介绍和华为官翻机相似，均表示以 99 新的 7 天机为主，且使用原厂物料，同样支持 7 天无理由、15 天质量问题换货和一年质保，甚至连宣传页面的展示方式都大同小异（看来是打断骨头连着筋啊）。
在可选型号上，荣耀似乎并没有什么特别原则，更像是「有什么卖什么」。比如 Magic 系列的翻新产品最新型号包括 Magic7、Magic6、MagicV2 等，数字系列则包括 300 和 400 两个系列。
而在价格方面，对于这些连电商平台都只有二手店铺在售的型号，我认为不如等新机发布后，购买打折的次新款。
OPPO
- OPPO 官方二手产品：京东、淘宝、拼多多搜索「OPPO 二手」；抖音搜索「OPPO 小当」
OPPO 官方二手机在今年也拓宽销售渠道，覆盖了京东、淘宝、拼多多以及抖音商城，不同平台店铺名称有所差异，不过和三星官翻机由「图腾」统一运营的模式类似，OPPO 官方二手机背后由合作伙伴「当换」运营。
顾名思义，OPPO 官方二手机是没有拆修、没有翻新过的「整机」，成色主要是准新、95 新和 9 新三个等级。在授权店铺购买的商品支持 7 天试用和全国联保，而且赠送一个非常有特色的「电池健康度承诺」服务，也就是在签收一年内如果电池健康度低于 80% 就免费进行电池更换，部分机型甚至承诺到手不是 100% 就免费换货。
但是价格方面并没有非常划算。在京东平台上，以销量还不错的折叠屏 Find N6 为例，准新成色的 16+512 版本券后价格 10049 并赠送一个原厂闪充充电器，自营全新机售价 10999 赠送一个耳机，整体来看二手机价格并没有非常有吸引力。爆款 Find X9 Ultra 的准新成色 12+512 版二手售价 7449 赠送原厂闪充充电器，自营全新机国补后竟然只要 6999，不仅价格更便宜，还能从耳机、云台支架等赠品中自选并参加直播间的加购活动——我一度以为是我选错了规格导致价格倒挂。
不过在其他电商平台上的授权店铺有上架平板电脑、耳机、手表等官方二手产品，价格方面比手机产品要好一些。感兴趣的朋友可以去搜索对比。
电脑办公类
微软 Surface
- 微软认证翻新 Surface：微软官方商城
本年度在售的微软 Surface 的官翻产品少了很多，所展示的零售货源只有 Surface Pro 9、Surface Laptop Go 3 还有两款全新的 Surface Pro。然而实际上有货可选的仅有 11 代的全新 Surface Pro。
不过这款官翻商品的价格非常出乎意料。其中 10 核骁龙处理器、16+256 的 WiFi 版官翻售价当前处于 7 折促销（指与原官翻售价相比），仅仅只需要 5172 元，而官方商城全新产品售价 9278 元，价格等同于腰斩；12 核处理器搭配 16+512G 的 WiFi 版官翻售价也只需 6600。
虽然商城里已经没有同配置全新机在售，但官翻价格怎么看都是非常划算。
戴尔
- 戴尔官翻机：戴尔 Outlet 专区查看购买渠道
原先戴尔 Outlet 专区目前已经不再以官方商城名义销售官翻商品，不过提供了 3 家具有代理授权的拼多多店铺。
这三家店铺的代理范围大同小异，都覆盖了笔记本、台式机和显示器。其中一家店铺上架的外星人星舰 16X 型号的游戏笔记本，CPU 为 U7-255HX、显卡为 RTX 5060、存储规格为 16+1T 的版本，官翻产品券后 11427 元；在售同型号全新机的 CPU 升级为 U7 270、屏幕更换为 OLED 材质，但国补后价格就飙升到近 18000 元。两者的 CPU 为同代架构且差异并没有很大，屏幕材质的变化也是见仁见智，对比下来官翻机的价格优势还是非常明显的。
在显示器产品上，「神机」UltraSharp 系列产品，25 年上市的 27 寸 4K 显示器 U2725QE，券后价格为 3513 元，而全新机售价在 4200 元以上。显示器这类产品本身就不易损耗，购买有保障的官翻机也是非常划算的选择。
联想、ThinkPad
- 联想、ThinkPad 官翻机：各电商平台搜索「ThinkPad 官翻」或「联想 官翻」
联想官方商城已经关闭了官翻产品销售入口，从原先链接跳转进去则是旧机回收活动的宣传。不过好在 ThinkPad 产品的官翻购买渠道还是比较丰富的，并且这些电商平台中的官翻店铺都是由同一家授权代理公司运营或有官方授权标识，其中除了 ThinkPad 品牌，也有一些联想扬天系列产品。
以 ThinkBook 16+ 为例。2025 款配置为 U5 225H+32+1T 的 3.2K 屏版本，拼多多店铺券后价格为 7739 元，同款全新产品京东自营店铺国补后售价 8456 元左右；同系列 2026 款的锐龙 CPU 非独显版本，官翻机和全新机到手价分别在 7539 元和 8999 元左右。整体来看两代产品的差价不是特别大，官翻机略有价格优势。
而来到独显版本，配置为 U7 356H+32+1T+RTX5060 的商品，官翻机和全新机的到手价只差 100 元左右，这很难不怀疑官翻店铺所售的该产品其实是全新机。
华硕

两年前表扬过华硕终于重视了官翻产品，今年看了官方商城发现只上架了两款商品。但实际上，华硕一共有 5 款商品在售、4 款有货，只是他们都做到了同一个链接的不同 SKU 里。
产品方面，无畏 Pro16 锐龙版，采用 AI9 H456 CPU、存储为 32+1T 规格的机型，官翻机售价 8099 元，附赠一元加购鼠标和电脑包的福利；京东自营店铺国补到手价 8456 元，赠送一个不如不送的 Microsoft 365 个人版 3 个月订阅权益。
其他产品价格都是类似的情况。考虑到赠品价值不高、全新机还有国补，官翻机的价格优势并没有凸显出来。
雷神

上一次搜索到这俩海尔的小微企业官翻店时还让我惊喜了一会，两年之后却已物是人非：机械师已经清退了店铺，雷神官翻的主营产品也都是鼠标键盘、手柄、显示器之类的产品。
价格倒也不贵，显示器价格从 400 元到 1000 元不等，鼠标手柄都在百元以下，不追求极限操作的话这些产品性价比其实也不错。
爱普生打印机
爱普生打印机的官翻产品在京东和拼多多有渠道，同时在自家的小程序官方商城中也有销售，京东价格更优惠的同时还赠送相纸和打印纸。在售商品包括 L4266、L4268 这两款千元级别的产品，另外京东还有一款 1899 元的 L6278，以及上架了原装墨水（当然，墨水不是官翻）。
这几款商品相比全新机都有三成左右的优惠，对于总价本就不算高的产品来说还是足够有诚意的，家里有小学生的朋友可以选购这样一台品牌靠谱的官翻打印机。

            Abstract:LLMs now sit on every side of evaluation: as examinees scored on benchmarks, judges of other models' outputs, and raters of human-generated content. Each paradigm can be viewed as a measurement problem, where a latent property of an object is probed with items from an instrument (e.g., benchmark) by raters. Standard evaluation practices often neglect the contributions of each core component to the end result, limiting our understanding of what is being measured. Rasch measurement theory (RMT) is well-suited to this kind of problem. RMT decomposes ordinal ratings into separable facets on a common scale. Overall, we argue that RMT belongs in the toolkit for evaluating LLM-as-examinee, -judge, and -rater paradigms.
